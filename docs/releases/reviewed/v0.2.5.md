You can play with the cat now, and messages you send no longer show up twice.

## New

- Double-tap the cat to make it hop, hold it to pet it, or hold and drag to toss it. It springs back home when you let go.
- Settings now asks for a plain server address like `https://mewla.example.com`, and says what is wrong when an address doesn't work.

## Fixed

- A message you send no longer shows up twice when it has blank lines, trailing spaces or a paste.
- The cat's wake-up hop is no longer cut off at the edges.
