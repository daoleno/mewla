Hyperliquid is now a plugin, on mainnet or testnet. Update the app to 0.2.46 as well.

## New

- **Hyperliquid in Extensions, on mainnet or testnet.** Brain and Workers can read markets, order books, candles and funding, and an account's positions, orders, fills, funding payments and PnL. Choose Mainnet or Testnet when you connect; each is its own account, tagged on its card and in every tool result, so testnet is never mistaken for mainnet.
- **Trading with an API wallet, off until you turn it on.** Paste an API wallet key to let Brain place, change and cancel orders and set leverage. An API wallet can trade but cannot withdraw, Mewla refuses your main wallet's key, and there is no withdrawal or transfer anywhere. Each order result states the network and exactly what was sent, and an order is never retried.
