Diagrams draw right in Chat, every file an agent names opens with a tap, Mewla is back in seconds after you switch networks, and each update now tells you what is new in Brain's chat; update both the app and Mewla on your computer.

## New

- **Diagrams and files, right in Chat.** A `mermaid` code block in a reply or in a Markdown file you open draws as its diagram, in light or dark with the app. It is laid out for your screen: a wide flowchart turns top to bottom on a phone, and tapping it opens it full screen with zoom. Diagrams are drawn in the app itself, with no network. Every file an agent names opens with a tap (see Fixed).
- **Back in seconds after switching networks.** Going from Wi-Fi to mobile data and back, Mewla reconnects as soon as the network does instead of waiting out its retry, and a connection that stopped answering after the switch is replaced within seconds. On Mewla Relay, once your computer's own network can be reached, the connection moves onto it without dropping.
- **Every update, told in Chat.** After an update, the first time you open Brain it shows what is new once, each item with something to try. Brain's chat keeps a line for every update ("Updated to 0.4.9 · What's new"), and About shows the notes again.

## Fixed

- **No more flapping between online and offline.** The app used to close a working connection whenever a faster path seemed to appear, and fall back again when that path died, which looked like Mewla dropping offline over and over at home. It now keeps the connection that works.
- **"isn't online" instead of a TLS error.** When a computer on Mewla Relay is not on the relay (switched off, asleep, not running Mewla, or the phone's network blocks the relay), its card now says `<name> isn't online` and suggests `mewla doctor` on the computer, with the phone's own error under it, instead of "TLS handshake failed".
- **File links in Chat open.** A file an agent names by any path, such as `worklog/plan/DESIGN.md`, `./out/report.pdf` or `src/main.go:42`, is now a link once your computer says the file is there; a relative path is read from the folder the agent works in. Before, only paths under your home folder were links. A computer still on an older Mewla links only those until it is updated.
- **Windows: `mewla update` restarts Mewla installed over SSH.** Mewla installed over SSH now starts the way the logon task starts it, so `mewla update` and `mewla restart` restart it with no Stop-Process. The update onto 0.4.9 still runs your current version's update, so if it asks you to stop and start Mewla, do that once; later updates restart it themselves.
- **A Brain thread's chat opens on its own messages**, at its end or where you were reading, instead of showing the previous thread's messages for a moment and missing its place.
- **iPhone and iPad keyboards: Alt+b and Alt+f jump by word in the terminal.** A character Option types, such as @ with Option+l, still types it.
- **A Friends post's full-screen video keeps Close below the status bar.**
