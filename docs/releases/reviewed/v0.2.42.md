Mewla uses far less CPU while it sits idle, most of all on a Mac.

## Fixed

- **An idle computer no longer keeps Mewla busy.** With an agent open but nothing happening, Mewla looked up that agent's conversation file twice a second, starting several helper programs and reading dozens of session files each time. It now reuses the answer until the agent's state changes, so an idle Mac that sat at about a fifth of a core drops to a small fraction of that.
- **A finished Session that is not Mewla's no longer causes a retry every ten seconds.** When a Worker ended and left an ordinary shell behind, Mewla correctly refused to close it but kept trying and logging the same refusal forever. It now reports it once and leaves the shell alone.
