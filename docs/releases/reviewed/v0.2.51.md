The app now tells which agent a Worker is from the executor Mewla started it with, and Claude sessions you start from the app are followed like the ones Mewla starts for you.

## New

- **Claude sessions started from the app are followed from their first moment.** Like Workers Mewla starts itself, they now run with their own conversation id and Mewla's hook file, so a turn's start and end, and a permission prompt, reach Mewla straight from Claude. `mewla worker approvals` and `approve` work on them too. A session that already names a conversation or carries your own `--settings` is left as it is.

## Fixed

- **A Worker started from a custom executor shows as the agent it runs.** An executor you named yourself in `executors.toml` (a Codex wrapper, a Claude with fixed flags) used to look like a plain terminal, and a command that only mentioned an agent could be taken for one. The daemon now records which executor started each Worker and sends its agent family with it; the app uses that for the icon, the title and the agent-specific prompts. Update the app and the computer together: a computer on an older version does not send it, and its Workers show as terminals until it updates.
