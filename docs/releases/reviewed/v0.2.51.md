Codex sessions started from Mewla are now followed through Codex's own channel instead of its screen: Mewla knows the conversation from the first moment, sees each turn start and finish, answers permission prompts without typing, and sends your messages with a receipt. It also brings every paired phone your notifications, tells you when something failed instead of showing an empty screen, and stops trusting wording it should not trust.

## New

- **Codex Workers report what they are doing.** A Codex session started by Mewla runs with its own local control channel. Mewla learns the conversation id the moment Codex creates it, sees a turn begin and end, and shows Codex's own error (a rate limit, a refused request) instead of guessing from the screen. Helper conversations Codex starts for itself are ignored.
- **Codex permission prompts are answered without keystrokes.** `mewla worker approvals` lists a waiting command or file change, and `mewla worker approve` allows or declines it straight through Codex.
- **Messages to a Codex session you started are sent to Codex directly,** with a receipt that Codex echoes back, rather than pasted into the terminal and read back. A message Codex refuses is reported as not sent, and one whose outcome is unknown is never sent twice.
- **Brain's quick replies are quiet.** The answer chips are now one line of small text under Brain's last message that scrolls sideways, instead of rows of outlined buttons above the composer. They hide while you are typing and are still a tap away from sending the text as typed. Brain offers at most three, only for a real decision, and no longer adds "skip" or "later", since not answering already means that.
- **Every paired phone gets your notifications and live state.** Until now only the most recently connected phone was told; each paired device is now notified, and a tap on any of them answers it. Revoking a device stops its notifications.
- **Stats says when it failed to load.** A failed load shows "Stats didn't load" with **Try again**, instead of looking like you have no stats yet.
- **Codex commands that cannot be listed say so.** The composer shows "Codex commands unavailable" instead of "No matching command" when the list has not arrived.
- **Quick Tunnel status is read from cloudflared itself.** The tunnel address and readiness come from cloudflared's own status endpoint, not from its log lines.
- **Android only allows plain HTTP to your own computer, not to Mewla's domains.** LAN and Tailscale addresses keep working; `mewla.ai` and its subdomains must use HTTPS.

## Fixed

- **A Claude hook is accepted only from the session Mewla launched.** A hook event carrying another conversation's id is rejected, and a permission decision only answers a request from the conversation that asked. A Worker still follows its own `/clear`, `/compact` and resume.
- **Codex conversations are found when the session has helper threads.** A thread listing the newer Codex sends in a different shape no longer fails the lookup.
- **A pairing that finished on the computer but not on the phone can be resumed.** The recovery check needed a daemon id that Link pairing links never carried, so it always gave up with "Pairing didn't finish". The phone now works the id out from the computer's key.
- **Removing the current computer no longer silently switches to another.** If the saved current computer is gone, the app shows "no computer" instead of connecting to the first one in the list.
- **A failing `ps` no longer rewrites your Workers.** When the process list cannot be read, Mewla keeps what it knew about each Worker instead of guessing from the terminal.
- **Mewla decides a tmux server or pane is gone from the socket, not from tmux's wording.** Cleanup after a Worker ends no longer depends on message text.
- **Git errors are recognised in any language.** Opening the diff of a folder that is not a repository works under non-English locales.
- **Messages that mention Daytona or a sandbox are no longer hidden.** Mewla only drops the AGENTS.md text Codex injects, not messages that happen to share words with one person's project.
- **Compaction summaries and interrupt notes are marked by the provider, not guessed from English wording.** Memory search and Watch no longer treat them as something you said.
- **Calendar and Telegram report writes that fail.** A reminder or message state that could not be saved is logged once and shows up in Watch.
- **The Calendar wakes when something is due instead of every second**, and Telegram projects the Brain conversation only when it changed.
- **Terminal icons follow the program that is running.** They no longer guess from the folder name or the last lines of output.
- **Browsers authorize with a header, not the address bar.** The web UI no longer puts its one-time signature in the URL, and Mewla no longer learns its own public address from whatever `Host` header a request carries.
- **Mewla no longer copies every Work each time something happens.** Looking up one Work, one session or one pending message used to clone the whole Work store; it now reads the one it needs, which removes most of the memory churn behind an idle daemon's CPU use.
- **Old pairing and compatibility paths are gone.** Version 2 Link pairing links, the Codex binary scanner for slash commands, five unused session actions and several start-up clean-ups were removed. Generate a new pairing code if you saved an old Link one.
