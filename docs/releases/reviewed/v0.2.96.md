Connect Gmail, Calendar and Drive through Google, and Tailscale now connects reliably through Chrome.

## New

- **Google Workspace.** Connect it and agents can read your Gmail, Calendar and Drive through Google's `gws` tool. Mewla installs `gws`, sets up the Google Cloud project for you when one Google Cloud account is signed in and turned on, and asks for your own OAuth client, which Google offers no way to create for you. Reads run directly; changes need writes turned on and the task's authorization.

## Fixed

- **Tailscale connects through Chrome again.** It follows Tailscale's current admin console: it waits for the page to load before judging whether you are signed in, fills in the credential form's scopes, description and tags, and tells you which page Chrome ended on when it is not signed in.
