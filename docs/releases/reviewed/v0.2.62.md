A cat to keep you company, Claude Auto mode, and steadier Workers, choices and notifications.

## New

- **A cat that lives in Mewla.** Turn on the cat game in Settings → Labs (off by default). Name your cat, watch it keep a home, go on outings while your Workers run, and collect postcards and souvenirs. It is English only.
- **Claude runs under Auto mode.** Claude Workers use Claude's Auto permission mode instead of skipping every check.
- **Blocked actions go to Brain first.** When a delegated Worker is stopped waiting for a permission, Brain gets the first look before it reaches you.
- **Brain shows a computer as blocked** while it waits on a choice, a plan or a permission.
- **Resume readiness.** A resumed Claude session is recognised as ready for input as soon as it is back.
- **Simpler plugin setup.** Hyperliquid reads with no setup, and a trading key can be added on its own. The Google connect screens are quieter.

## Fixed

- **Choice cards stay tappable** whatever state the Session shows, and stay put when a prompt only moves to another tab. A question never shows Allow and Deny.
- **One push per finished Work run**, and none while the app is open in front of you.
- **Brain hears when a Worker stops.** A Worker's agent activity is linked to it after its first check-in, so a stop is no longer missed.
- **Mewla no longer reaches your live tmux by accident.** A plain `tmux` typed in a Mewla pane can no longer fall back to the default server, and the guard no longer spins when a wrapper runs it again.
- **A restart storm on the computer is gone.** Releasing a Worker that has nothing to change writes nothing, finished teardowns are remembered, and startup retry ends when the generation changes.
