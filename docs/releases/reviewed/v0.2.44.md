Claude Workers keep their own conversation, and Codex usage no longer borrows your sign-in token. Update the app to 0.2.44 as well.

## Fixed

- **Two Claude Workers started in the same folder no longer mix up their conversations.** Each delegated Claude Worker is now launched with its own session id, so Mewla knows which conversation is whose from the first second instead of matching it by start time. This mattered most on macOS.
- **Codex usage comes from Codex itself.** Stats used to read Codex's sign-in file and send its token to an undocumented ChatGPT address. It now asks Codex (`codex app-server`) for the plan's usage windows, so Mewla never touches that token. If Codex has no subscription windows to report, the card is hidden.
- **The Brain's Codex session is checked less often.** It looked up the running Codex process every second even when nothing had changed. It now does that once every 30 seconds.

## Added

- **`MEWLA_PPROF_ADDR` shows what the daemon spends its time on.** Set it to a loopback address and the daemon serves Go's profiler plus `/debug/spawns`, a count of the helper processes it starts and why. It is off unless you set it.
