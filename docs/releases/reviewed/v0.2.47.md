Claude Workers now tell Mewla when a turn starts and ends, and the daemon does far less work while nothing is happening.

## New

- **Mewla hears a Claude Worker's turns straight from Claude.** A Worker that Mewla starts runs Claude with a small hook file of its own, so the start and end of each turn, the conversation it belongs to and any permission request reach Mewla the moment they happen instead of being read back from the transcript. Your own Claude settings and hooks are left as they are.
- **`mewla worker approvals` and `mewla worker approve` answer Claude's permission prompts without a keystroke.** For a Claude Worker that asks before running a command, `approvals` lists what it is waiting on and `approve -id <worker> -approval <id> -option allow|deny` answers it. Claude's own prompt still decides if nobody answers.
- **`/debug/spawns` names the code that starts each helper process.** With `MEWLA_PPROF_ADDR` set, every count now comes with the chain of callers behind it, so a busy loop can be found in one request.

## Fixed

- **An idle daemon starts about 60% fewer helper processes.** Each check of a Worker's pane used to run five tmux commands; it now runs one. With four Workers open the daemon went from about 67 to about 25 helper processes a second, and its idle CPU use dropped by roughly a third.
