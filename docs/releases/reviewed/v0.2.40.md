Resources now shows a Mac's real CPU, memory, disk and processes. Update the app to 0.2.40 as well.

## New

- **Resources works on a Mac.** The Resources screen of a Mac shows its CPU (total and per core), memory used and available, swap, disk reads and writes, and the processes using the machine, grouped by app the way a Linux computer's are.
- **A Mac shows memory pressure.** A Mac has no pressure-stall figures, so the Pressure card shows the system's own memory pressure level (Normal, Warning or Critical) with its recent history, and Brain is told when it turns Warning or Critical.

## Fixed

- **Resources no longer says Normal when it knows nothing.** A computer that reports no readings shows a grey ring instead of a green Normal over a screen of dashes.
- **Shared memory is no longer shown as 0 B on a Mac.** The Mac does not report it, so the line is left out.
