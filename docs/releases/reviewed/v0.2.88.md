Your first minutes with Mewla no longer get stuck: pairing is quick, Brain starts by itself, and when something is missing it tells you what to do.

## New

- **Brain starts by itself.** It picks an agent you are signed in to, and it starts on a computer that has no tmux running yet, after you install or sign in to an agent later, and after a reboot. When Brain can't start, it says why and what to do, and starts on its own once you have done it.
- **Pairing opens Brain.** After you pair a computer, the app lands on Brain instead of Sessions.
- **Pairing takes seconds.** Over remote access it now takes about 7 seconds instead of more than a minute. If remote access isn't ready, `mewla pair` waits for it after you sign in, and says so if it can't get there, instead of showing a QR code that won't work away from home.
- **The QR scanner asks for the camera** when it opens, and if you said no it tells you how to turn it on, with an Open Settings button.
- **Switch executor lists only agents installed on the computer,** signed-in ones first. The button appears only when there is another agent to switch to.
- **Mewla updates the computer for you on Linux.** When nothing is running, a new version is installed in place, and rolled back on its own if it doesn't come up. Settings shows the computer's version with an Update button. macOS computers still update with `mewla update`.
- **Settings tells iPhone users about newer TestFlight builds,** with one tap to open TestFlight.
- **Browser use is one quiet row** on the computer page, and it only asks for setup when you start it.
- **`mewla doctor` sees agents the way the running Mewla does,** and tells you when the running Mewla is ahead of your terminal.
- **Update the app and the computer together.** Brain's agent list and problem messages need both on this version.

## Fixed

- **iPhone connects over remote access.** A hosted computer's own address now accepts the connection an iPhone makes.
- **Settings never asks for a computer newer than the app.** A computer on the same version as your app is now always accepted.
- **An empty Brain chat says it can't reach the computer** instead of "Ready" when the computer is offline.
- **Browsers are approved by number** (`mewla devices approve 3`), and the waiting screen shows the command.
- **The iPhone composer rises with the keyboard** in the interface mode.
- **The scanner no longer says it is looking for a code while the camera is off.**
