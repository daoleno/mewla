## Highlights since v0.2.1

- **Plugins:** connect a service from the Plugins list in one tap. Signing in from the web UI brings you back to the web UI. A sign-in in progress shows as one status card. Linear's access summary is now correct.
- **Brain:** when you refresh, Brain shows a loading outline and a "Connecting…" composer instead of the empty "Ready when you are" screen. Work shows one running count.
- **Look:** an original stroke-rounded icon set, a new Skills icon, monochrome service marks, and one sidebar list.
- **Under the hood:** internal names are now brand-neutral or Mewla. Because of this, the phone app and the daemon must both be on v0.2.2: an app older than v0.2.2 can't connect to a v0.2.2 daemon. Update the app and the daemon together.

## Known limitations

- iOS is still build-from-source. There is no Mewla TestFlight build yet.
- Signing in to the Slack, GitHub and Google plugins from the app needs each publisher's callback updated to `mewla://plugins`.
- Slack connects only from the Mewla app, not from the web UI.
