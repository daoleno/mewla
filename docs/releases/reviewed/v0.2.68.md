Claude agents that Mewla starts now run without per-action approval by default.

## Changed

- **Claude no longer stops to ask before each action.** Claude agents that Mewla starts, including Brain, Workers and scheduled actions, now run in bypass-permissions mode by default, so deploys and external writes are no longer blocked by Auto mode. A `--permission-mode` you set in your executor command still wins.
- **No first-run warning.** The bypass-mode warning dialog no longer appears when an agent starts.
