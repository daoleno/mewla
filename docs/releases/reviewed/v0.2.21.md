Agents get through browser tasks faster and use Mac apps more reliably. Update the app to 0.2.21 as well; on iPhone it is build 59 in [Mewla Preview on TestFlight](https://testflight.apple.com/join/nMQheDCE).

## New

- **Faster browser use.**
  - Agents no longer pull the whole page after every step: they look up only the buttons and fields they need, then run the flow in one go. A flow sends, submits or pays only what you already approved; otherwise it stops before that step and the agent asks.
  - Page snapshots, console logs, screenshots and downloads the browser tools make no longer land in the project folder. They are kept in Mewla's own folder, `~/.mewla/agent-use/browser-files`, which keeps the newest 256 MB.
- **Agents can open a Mac app that isn't running**, by its name, in the background behind the app you are using. They open only apps, never a file or link.

## Fixed

- Agents no longer pause for their own display wake-up, or for a finger resting on the trackpad. Key presses, clicks, moving the pointer and scrolling still pause them, and a pause now says which input it saw.
- An element's number never moves to a different element. When an element has changed or gone, using its number is refused with "read the app again".
- A click on an app's window behind others:
  - presses the button or control there through accessibility where it can;
  - otherwise only says the click was sent, not that it worked, so the agent checks.
- A screenshot of one app's window names the app actually covering it.
- On a Mac set to another language, agents also find an app by its English name, such as Notes for 备忘录.
- A request from your other computer no longer asks again for the actions you already asked for in it. Anything more, such as paying or sending to someone else, still asks first.
