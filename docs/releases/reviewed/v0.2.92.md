Give Codex Workers their browser and computer tools, and make updates finish on a slow connection.

## Fixed

- **Codex Workers get the Chrome and computer tools again.** A Codex Worker started from Mewla could not see `mewla_chrome` or `mewla_computer`, so it could not use your Chrome or your screen. The tools are now added before Codex's own server is set up, and that server receives them too.
- **Setting up Chrome offers the Mewla extension first.** On a computer that already has the older Playwright extension but no key, **Set up** now walks you through adding the Mewla extension, which needs no key. Pasting the Playwright key still works.
- **Updating no longer fails on a slow link.** The download used to be cut off after 15 seconds in total, so a 28 MB update could never finish on a slow connection to GitHub. It now continues as long as data keeps arriving and stops only after 20 seconds with none.
