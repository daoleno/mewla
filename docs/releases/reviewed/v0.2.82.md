Phone use (Android, Labs) now reaches your app clones, types into apps like WeChat, and works faster.

## New

- **Phone use opens app clones.** Your agent can see and launch a cloned app, such as a second WeChat, and it shows up next to the original.
- **Typing lands in apps like WeChat, Chinese included.**
- **Phone use sees the screen after each action, not before it.** The picture the agent gets back is fresh, and it says so when it can't be.
- **Known flows run in one call.** When your agent already knows the steps, it can do them in a single go.
- **More apps are readable.** Apps that report nothing visible can now be read by element.
- **Actions settle faster.** Your agent waits less between taps.
- **Update the app and the daemon together.** Phone use needs both on this version.
