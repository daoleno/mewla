## Fixed

- **Turning on Friends no longer turns on remote access.** It now signs this computer in to your Mewla account and nothing more. If you already signed in to Friends on a computer, run `mewla logout` once to turn remote access off; Friends keeps working. With Friends on, `mewla logout` only turns remote access off.
- **The reply suggestion buttons under Brain's messages are gone.**
