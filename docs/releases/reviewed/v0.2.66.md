Hyperliquid now reads markets and accounts without any setup, and adding a trading key no longer decides whether it works.

## Fixed

- **Hyperliquid reading no longer depends on the trading key.** Brain can read markets, prices and an account's positions, orders and fills as soon as the service is on; adding or removing an API wallet key only turns trading on or off and leaves reading as it was.
- **A Hyperliquid account you disconnected comes back reading.** It is no longer left behind with a stale pending key.
- **Hyperliquid's page is simpler.** Trading is one optional **Add API wallet key** row, and the service is described plainly as the exchange: markets, accounts and trading.
