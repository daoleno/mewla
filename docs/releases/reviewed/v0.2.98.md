Agents get a private virtual screen on Linux, you stay in charge of the computer without pausing them, and Git review, chat Markdown and the terminal moved to new engines.

## New

- **Virtual screen (Labs, Linux).** Agents' browsers and desktop apps run on a private screen of their own. Screen lists every agent, each with a live view, and Watch, Take over, Stop and Hand back. Phone is a row in Screen, and Stop lives only in Screen.
- **You stay in charge without being in the way (Mac and Linux).** Using the keyboard or pointer, or opening Watch, no longer pauses the agent: it is told what you did and decides what to do next. A key or drag you are holding is still let go.
- **Mac background work.** An agent can drag in an app behind your windows, choose from a pop-up in one step so the menu is open for only milliseconds, and gets clearer guidance on when to use the screen and when to use an app.
- **Git review with Pierre Diffs and Trees.** The minimum iOS version is now 17.5, and Android needs WebView 123.
- **Chat Markdown on one standard parser.** Messages render as standard GitHub-flavored Markdown, and blockquotes keep their blank lines.
- **GitHub extension on GitHub's official MCP server.** When GitHub is unreachable it shows Unavailable with the reason and reconnects with backoff.
- **Terminal on libghostty-vt 1.0.**
- **Connection path.** The menu and the Computers list show how each computer is reached: LAN, Tailscale or relay.
