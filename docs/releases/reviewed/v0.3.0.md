Mewla no longer needs tmux: it runs your agents itself, on Linux, macOS and now Windows, and Git review becomes a working tool.

## New

- **Mewla no longer needs tmux.** Mewla now keeps every agent's terminal itself, so installing it is one command with nothing else to set up. Agents keep running while Mewla restarts or updates, and the Terminal shows them exactly as before.
- **Update the App with Mewla.** This release changes Mewla on your computer and the App together: after `mewla update`, update the App on your phone too (the new APK on Android, TestFlight on iPhone).
- **Mewla runs on Windows.** In PowerShell, `irm https://mewla.ai/install.ps1 | iex` installs it for your user, with no administrator, WSL or tmux. It starts when you log in and updates itself.
- **Your running agents move over by themselves.** After the update, each agent Mewla started in tmux finishes the turn it is on, then continues in Mewla with the same conversation, Work and history. Nothing is resent or lost. An agent that can't be resumed keeps running in tmux, and Settings tells you how many still do; if that is Brain, a fresh Brain takes over with its handoff.
- **Watch your agents from any terminal.** `mewla attach` lists your running agents to pick one (or name it: `mewla attach brain`), shows it in your terminal and lets you type into it; Ctrl-\ detaches and the agent keeps going. `mewla attach --all` shows every agent at once, side by side.
- **Scroll back through an agent's Terminal.** History keeps loading as you scroll without jumping, search finds text in it, and you can jump to the previous or next prompt. Tap a link or file path to open it, copied lines that wrapped come back whole, and a swipe in a full-screen program such as vi moves its cursor.
- **Git review is a working tool.** Staged and Changes groups, stage or discard a hunk (with undo), commit, push, pull, switch branches, browse history, and ask the agent about a change.
- **Failed steps stay out of the way.** A failed tool call, and a failed or blocked agent's status row, start collapsed.
- **Screen on the computer itself** shows who is using it, with Stop, instead of a live view of itself.

## Fixed

- **A stalled Worker** resumes when it reports progress, and a refused progress report says why and which turn to use.
- **Mewla does far less background work.** Usage and stats read only what changed since last time, and agent checks run every few minutes instead of on every refresh, so an idle computer stays quiet.
