This release updates the libraries Mewla is built on to close known security problems. Update the app to 0.2.31 as well.

## Fixed

- **Security updates for your computer's Mewla.** Mewla now builds with a newer Go release and newer networking, image and text libraries. This closes known problems in how images, hostnames and web requests are handled.
- **Security updates for diagrams.** The diagram renderer in chat is updated from 11.6 to 11.16, which fixes several known problems. Diagrams look the same as before.
