Generate images and video from Brain with two new plugins, and see Chat for every Session again.

## New

- fal plugin: Brain can search fal's image, video and audio models, such as Seedance. Paste a fal key under Extensions → fal. Generating costs money, so it stays off until you turn on "Make changes when asked".
- Image generation plugin: point it at any OpenAI-compatible images endpoint with an API key, and Brain can create and edit images.
- Generated files are saved under `~/.mewla/media/`.

## Fixed

- Chat was empty for Sessions whose folder name contains a space, while the Terminal showed them.
- Notes saved next to Work files no longer show up as broken Work.
