## Highlights since v0.2.0

- Every Work slip can move forward: Accept, Reply, Snooze, Not needed anymore, Stop or Retry with Brain, so nothing stays stuck waiting.
- The cat shows what Brain is doing and answers when you tap it.
- Web UI fixes: chat scrolling, file upload, a compact New session pill, and menus where each destination has one home.
- Brain now matches the Seal & Slip design: Work slips, the Work column on wide screens and the Work sheet on phones, and the goal line.
- Rewritten README and docs, organized around the jobs readers come for.
- Zen compatibility is removed: the `zen` command alias, the `~/.zen` migration and the `ZEN_*` environment aliases are gone. Use `mewla` and `~/.mewla`.

## Known limitations

- iOS is still build-from-source. There is no Mewla TestFlight build yet.
- Signing in to the Slack, GitHub and Google plugins from the app needs each publisher's callback updated to `mewla://plugins`.
