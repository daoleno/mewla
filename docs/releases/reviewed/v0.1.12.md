## Highlights since v0.1.11

- Resources is now a machine-level dashboard with current-server polling, clearer process/container identity, and telemetry that stays bound to the selected server.
- Terminal output arrives with lower latency, preserves native scroll state, and avoids stale frames while live rows update.
- Brain no longer duplicates user messages and keeps transcript/executor bindings correct when switching executors.
- The current-server resource navigation and polling path is complete, with focused contract coverage for the shared control-plane boundaries.

## Known limitations

- iOS Preview distribution remains subject to App Store Connect processing and Apple's Beta App Review. A successful signed upload does not by itself make the build installable for external testers.
- Android is distributed as a signed arm64 APK and has no Play Store package; users may need to allow installation from unknown sources.
