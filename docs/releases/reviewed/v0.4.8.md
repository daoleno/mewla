The agent browser and its pages survive restarting or updating Mewla, a Mac's Screen shows each agent's browser window, a Worker that is still working is no longer reported lost, and Mewla no longer needs tmux at all; update Mewla on your computer, since all of this comes from it.

## New

- **The agent browser survives a restart or an update.** Restarting or updating Mewla keeps the agent browser, the pages it has open and the agent screen. The first update onto 0.4.8 still closes an open agent browser page once; from then on they stay.
- **Screen on a Mac shows the agents' browser windows.** An agent that only uses the browser is listed in Screen under its name, first: a live view of just its window, where your typing and clicks reach that window only, with Hold, Let the agent go on, and Stop. A page it leaves open for you, such as a sign-in, stays after its turn, and its Work card opens Screen at it.
- **Mewla no longer uses tmux.** Every Session runs in Mewla's own session host. An `executors.toml` that still says `runtime = "tmux"` keeps working, and Mewla removes that line. Agents an old Mewla left running in tmux are no longer listed; end them in tmux if you still need to.

## Fixed

- **A Worker that is still working is no longer reported lost.** After a restart, or during a long quiet step, a working Worker could be marked lost and its turn given up. It now keeps its turn while its screen shows it working, and is only reported lost after real silence, with what was last seen.
- **A Worker's open page keeps its Work open.** Work is not closed as finished while its Worker still has a browser page open for you.
- **A full agent screen makes room.** When every agent display is taken, a finished Worker's idle display goes to the next agent instead of that agent's browser failing to start.
