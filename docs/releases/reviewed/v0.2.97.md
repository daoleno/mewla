The timeline reads shorter and calmer: finished tool calls fold into one row, subagent work shows under the task that started it, and Sessions directories fold.

## New

- **Finished tool calls fold into one row.** Two or more finished calls in a row become a single line such as "Edited 1 file and ran 3 commands", and opening it shows the real rows. A call that is running, failed or waiting on you never hides in a fold.
- **Subagent work, where it belongs.** A subagent call is titled with the task it was given instead of "Use Task", and a Claude subagent's own steps appear under the row that started it.
- **Sessions directories fold.** Tap a directory name to fold its Sessions. A folded directory still shows how many Sessions it holds and the most urgent state among them (needs you, then failed, then running), so nothing waiting on you is hidden. Folds are remembered for each computer.
- **Smoother motion.** Disclosures, folds and new rows ease in briefly instead of snapping. Rows that merely scroll into view do not animate, and reduced motion turns it all off.

## Fixed

- **The timeline holds steady.** A fold keeps its place and your reading position when another call finishes into it.
