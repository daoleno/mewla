Codex's Status is now read from Codex itself, and a Codex that Mewla starts is no longer searched for. Update the phone app together with the daemon to get the new Status sheet.

## New

- **Status for a Codex chat comes from Codex, not from its screen.** Type `/status` in a Codex chat to see the model, approvals, sandbox, token use and context left, plus the account and its usage limits when Codex is signed in to ChatGPT. Mewla asks the Codex app-server it started, so nothing is typed into the Terminal and nothing is scraped from it. A Codex you opened by hand has no such server; its sheet says so and points to `/status` in the Terminal.

## Fixed

- **A Codex Worker is no longer looked for while it starts.** Until Codex announces its thread there is nothing to read, so Mewla waits instead of searching Codex's database and open files, and a Worker that Mewla restarted around keeps reading its own thread.
- **Brain's view of a Codex Worker's transcript follows the same thread.** It no longer opens the process's files to work out which conversation a Mewla-started Codex belongs to.
