# Mewla 0.2.49

Brain, your calendar and Telegram now keep their history in a database, so a change writes only what changed instead of the whole file.

## New

- **Brain's history lives in one database.** Works, their events, Brain's conversation and the chat timeline were whole files that were rewritten on every change; on a large history that was about 60 MB of writing for one update. Now each change writes a few rows, an update takes about 50 milliseconds instead of most of a second,.
- **The first start after updating moves your data over, once.** Brain's state, the calendar and Telegram's state are converted and checked row by row before the new database is used. On a large history this takes a little while. If it fails, nothing is changed and the old files stay where they are.
- **The old files are kept in one dated folder.** They are moved to `~/.mewla/brain/legacy-state-<time>/`, `~/.mewla/legacy-calendar-<time>/` and `~/.mewla/legacy-telegram-<time>/`, and Mewla never reads them again. Delete a folder when you are satisfied.
- **Going back to an older version is a manual step.** After the move, an older Mewla stops at start instead of opening an empty history. To go back, stop Mewla, put the backed-up files back where they were, remove the new `.db` files and start the older version; anything written since the update is lost.

## Fixed

- **A busy history no longer slows `mewla brain work list` and `mewla brain context` down.** Reading right after a write used to wait while the files were reloaded; it now answers in about 50 milliseconds.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.49.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.48...v0.2.49](https://github.com/daoleno/mewla/compare/v0.2.48...v0.2.49)
