# Mewla 0.2.80

Your agents now run with full authority, so they no longer stop for approval prompts.

## New

- **Agents run with full authority by default.** Agents no longer stop to ask for approval before acting. Existing `auto` settings are upgraded automatically.
- **No more Safe/Autonomous choice in `mewla setup`.** `--profile` and `--yes` are removed; setup now always configures agents with full authority.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.80.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.79...v0.2.80](https://github.com/daoleno/mewla/compare/v0.2.79...v0.2.80)
