# Mewla 0.4.7

Brain runs on Windows with an npm-installed Claude Code, a question an agent asks before it can start shows in Chat for you to answer, and `mewla update` restarts Mewla onto the new version; update Mewla on your computer, since most of this comes from it.

## New

- **Sign-in and first-run questions are answered in Chat.** When Claude Code or Codex asks how to sign in, whether you trust a folder, or which text style to use, the Session shows it in Chat with its real choices, on the phone and on the web. The sign-in card opens the sign-in page and takes the code it gives you.
- **Screen keeps a Worker's browser page.** A page a Worker opens is listed under its name in Screen as soon as the window opens, and stays after the Worker's turn until the Worker closes, you close it, or it sits unused for an hour. The Work card opens Screen at it.
- **Several people on one Windows computer each get their own Mewla.** Installing for a second person no longer replaces the first person's start-at-login task or uses their Mewla; the second one starts on the next free port and says so.

## Fixed

- **Windows: Brain starts on an npm-installed Claude Code.** Brain on a Claude Code installed with npm ended the moment it started and a new one was started every half minute. It now runs, as on the official installer's Claude Code, and `mewla brain use claude` works again.
- **When Brain, a Session or a Worker cannot start, Chat says why.** It shows how the agent ended, with its exit code and what it printed, and Brain is not started again every few seconds.
- **`mewla update` restarts Mewla on Windows and Linux.** It used to leave the old version running and say "Stop and start mewla", with no way to stop it. Now Mewla restarts onto the new version, and your Sessions and Workers keep running. Updating to 0.4.7 itself still prints the old message: run `mewla` once afterwards and it restarts onto 0.4.7. `mewla restart` does it any time, and `mewla web` and `mewla pair` wait longer for a busy computer.
- **Agents installed for your login shell are found.** Claude Code or Codex installed with npm, nvm, fnm, Volta or bun, on your login shell's PATH only, is found when Mewla starts as a service.
- **A new Claude Session in a folder you pick starts ready.** Claude's "trust this folder" question no longer waits unseen in the terminal for a folder you chose in Mewla.
- **A message sent right after switching Brain arrives on its own.** It could be joined to an unsent line and hidden along with Brain's answer.
- **Windows: a folder Windows can't use says so.** A folder path over Windows' length limit is refused in words, and "Up a folder" in New Session works on Windows.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`.
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Windows x64:** `mewla-windows-amd64.zip`, or in PowerShell: `irm https://mewla.ai/install.ps1 | iex`
- **Android:** `mewla-android-arm64-v0.4.7.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.4.6...v0.4.7](https://github.com/daoleno/mewla/compare/v0.4.6...v0.4.7)

<summary>Verify downloads</summary>

`mewla update` and the installer check downloads for you. To check one by hand against `SHA256SUMS`:

```sh
grep 'mewla-linux-amd64.tar.gz$' SHA256SUMS | sha256sum -c -        # Linux
grep 'mewla-darwin-arm64.tar.gz$' SHA256SUMS | shasum -a 256 -c -   # Mac
```

On Windows, in PowerShell, compare with the `mewla-windows-amd64.zip` line of `SHA256SUMS`:

```powershell
(Get-FileHash mewla-windows-amd64.zip -Algorithm SHA256).Hash.ToLower()
```
