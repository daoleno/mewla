# Mewla 0.2.84

Phone use (Android, Labs) now shows apps in the floating screen the way they look on your phone.

## New

- **Apps look the same as on your phone.** The agent's screen now has your phone's real size and density, so text size and the amount of content match, and the floating screen is a true shrunk copy of it.
- **The screen follows Display size.** After you change 显示大小 or the font scale, the agent's screen is rebuilt to match instead of staying at the old size.
- **Taps land where the agent sees them.** The picture the agent looks at and the taps it sends now share one coordinate space.
- **Update the app and the daemon together.** Phone use needs both on this version.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.84.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.83...v0.2.84](https://github.com/daoleno/mewla/compare/v0.2.83...v0.2.84)
