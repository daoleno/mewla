# Mewla 0.2.68

Claude agents that Mewla starts now run without per-action approval by default.

## New

- **Claude no longer stops to ask before each action.** Claude agents that Mewla starts, including Brain, Workers and scheduled actions, now run in bypass-permissions mode by default, so deploys and external writes are no longer blocked by Auto mode, and there is no first-run warning dialog. A `--permission-mode` you set in your executor command still wins.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.68.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.67...v0.2.68](https://github.com/daoleno/mewla/compare/v0.2.67...v0.2.68)
