# Mewla v0.2.0

This release contains the reviewed changes on `main` since `v0.1.15`.

## Highlights since v0.1.15

- Zen is now Mewla: a new name, the seal-cat icon, and the app id `com.daoleno.mewla`. Mewla is a new app, so install it alongside or in place of Zen and pair again with `mewla pair`.
- The `zen` command keeps working as an alias for `mewla`, so existing scripts and habits continue to run.
- Daemon state moves automatically from `~/.zen` to `~/.mewla` on first start, and `~/.zen` stays as a link to the new location.
- A quieter Seal & Slip design across Sessions, Worker chat, the terminal palette, Calendar, Providers, Skills, Stats, Resources and Browser.
- Fixed a false "turn lost" report when several Workers start at the same time.

## Known limitations

- The old Zen app (`com.daoleno.zen`) does not receive Mewla updates. Install the Mewla APK to keep receiving releases.
- Android is distributed as a signed arm64 APK. Installing it may require allowing apps from your browser or file manager.
- iOS Preview delivery depends on App Store Connect accepting the upload for the new Mewla bundle. TestFlight may be blocked until the account owner resolves Apple's agreements and creates the Mewla app records.

## Install

Download `mewla-linux-amd64.tar.gz`, `mewla-linux-arm64.tar.gz`, or `mewla-darwin-arm64.tar.gz` for your host, plus the Android APK and `SHA256SUMS`. Extract the archive, install `mewla` on your `PATH`, run `mewla`, then create a pairing link with `mewla pair https://your-origin`.

Apple Silicon support requires `tmux` (`brew install tmux`). The macOS binary is cross-built; validate it on a real Apple Silicon host before operational use.

The iOS Preview is distributed through TestFlight at <https://testflight.apple.com/join/rTKCDzMt>, subject to Apple's beta approval and processing.
