# Mewla 0.2.87

Finished Work now closes itself, and the terminal key bar behaves on foldables and after rotation.

## New

- **Work closes itself.** A finished Work no longer waits for someone to close it. Mewla settles the plain cases on its own, such as a failed or replaced scheduled run, a newer resource reading, or a request that can no longer be delivered. For the rest, a model reads the Work, its events and the chat and decides: done, cancelled, or keep open. These closes can be undone: ask about the Work again and it reopens.
- **Update the app and the daemon together.** Work needs both on this version.

## Fixed

- **The terminal key bar stays with the keyboard.** After rotating a phone or folding a foldable iPhone, the key bar no longer floats up leaving an empty strip at the bottom of the terminal, and the keyboard button no longer stays lit with no keyboard on screen. Show and Hide work with one tap.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.87.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.86...v0.2.87](https://github.com/daoleno/mewla/compare/v0.2.86...v0.2.87)
