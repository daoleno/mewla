# Mewla 0.2.90

Set up a computer from one command, let outside agents hand work to Brain, and give agents a faster browser and Mac.

## New

- **Set up a computer over SSH in one command.** `install.sh --remote` or `mewla setup remote` signs in with a device code, starts the background service and shows the QR code to pair your phone.
- **Outside agents can hand work to Brain.** Run `mewla agents mcp connect` to let Claude Code or Codex send tasks to Brain. Approve or revoke each one under Settings → Outside agents.
- **More than one account per agent.** `mewla brain executors add` and `mewla brain executors login` add a second Claude or Codex sign-in, and Settings → Agents shows which account each one is signed in as.
- **Faster browser use for agents.** Clicks and reads take much less time, pages can be read as a short list of controls and headings, and a whole flow can run as one script.
- **Faster Mac use for agents.** Reads and actions are quicker, Electron and Chromium apps such as Slack and Cursor are now readable, menu items can be chosen by name, and each action answers with what changed. Shortcuts that would quit an app are refused.
- **Copy from the web terminal.** Ctrl+C (Cmd+C on a Mac) copies a selection, including text a program selects with OSC 52 and text you drag-select.
- **One account list everywhere.** Every service shows its accounts as collapsed rows.
- **Screen explains the connection.** The badge says why a stream goes through the relay instead of directly.

## Fixed

- **Switching providers no longer breaks requests.** Request bodies now pass through unchanged, which ended the 502 errors and the sessions that were kept by mistake.
- **Long multiple-choice questions can be answered in the Brain view.** The answer used to fail on a long question.
- **A stuck follow-up no longer blocks sending to a Worker.**

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.90.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.89...v0.2.90](https://github.com/daoleno/mewla/compare/v0.2.89...v0.2.90)
