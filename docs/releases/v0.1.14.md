# Zen v0.1.14

This release contains the reviewed changes on `main` since `v0.1.13`.

## Highlights since v0.1.13

- Use Zen in your browser: `zen web` opens the shared client, now bundled with the daemon. The web terminal includes its own font, and pairing through a web address stays on that address.
- Connect a new device with a clearer pairing flow. Browser enrollment and device approvals show pending requests and their outcomes, and approvals clear when the trusted connection ends.
- Navigate with one consistent back button. Plugins now has real pages for each service, its accounts, permissions, and tools, with working browser URLs and back navigation.
- Plugin setup tells you when a service is ready for sign-in and when publisher configuration is still unavailable, so an unavailable integration no longer looks ready to connect.
- Terminal sessions wait for the server connection before opening, durability warnings refresh correctly, and web images use their loaded dimensions.
- The website and README now explain the first connection using the QR code printed by Zen.

## Known limitations

- Android is distributed as a signed arm64 APK. Installing it may require allowing apps from your browser or file manager.
- Each plugin still requires its provider's configuration and your account authorization. Availability in the service list does not guarantee a completed connection.
- iOS Preview delivery depends on App Store Connect accepting the upload. Recent uploads have been blocked by Apple's missing or expired agreements; the account owner must resolve those agreements before TestFlight delivery can succeed.

## Install

Download `zen-linux-amd64.tar.gz`, `zen-linux-arm64.tar.gz`, or `zen-darwin-arm64.tar.gz` for your host, plus the Android APK and `SHA256SUMS`. Extract the archive, install `zen` on your `PATH`, run `zen`, then create a pairing link with `zen pair https://your-origin`.

Apple Silicon support requires `tmux` (`brew install tmux`). The macOS binary is cross-built; validate it on a real Apple Silicon host before operational use.

The iOS Preview is distributed through TestFlight at <https://testflight.apple.com/join/rTKCDzMt>, subject to Apple's beta approval and processing.
