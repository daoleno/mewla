# Mewla 0.2.9

Mewla can now update itself on Android: Settings → About tells you when a new version is out, and one tap installs it.

## New

- Settings → About shows "Update available · vX.Y.Z" when a newer release exists. Tap it to download the APK. Mewla checks the release signature and the APK checksum, then opens the Android installer. Tap the row to check again at any time.
- The first update asks you to let Mewla install apps. Allow it, come back, and the installer opens.
- Extensions: tap a tool's row to see its inputs as a list of fields, with type and whether each is required.
- Extensions: fal now shows its own logo.
- Install v0.2.9 by hand once, as before. After that, updates come from About.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://raw.githubusercontent.com/daoleno/mewla/main/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.9.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.8...v0.2.9](https://github.com/daoleno/mewla/compare/v0.2.8...v0.2.9)
