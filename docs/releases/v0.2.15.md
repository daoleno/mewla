# Mewla 0.2.15

Mewla on a Mac now stays running.

## Fixed

- On a Mac with `mewla boot install`, Mewla restarts on its own whenever it stops, not only after a crash. Before, a stop that looked clean left your phone unable to reach the Mac until someone started Mewla again. Run `mewla update` to get the fix; it reinstalls the service for you.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://raw.githubusercontent.com/daoleno/mewla/main/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.15.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.14...v0.2.15](https://github.com/daoleno/mewla/compare/v0.2.14...v0.2.15)
