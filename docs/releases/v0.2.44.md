# Mewla 0.2.44

Your phone now goes straight to your computer when it can, Claude Workers keep their own conversation, and Codex usage no longer borrows your sign-in token. Update the app to 0.2.44 as well.

## New

- **A phone paired through Mewla Link uses your Wi-Fi/LAN or Tailscale when it can reach the computer, and the relay otherwise.** Screen and the rest of the app share the choice. The Screen badge says **LAN**, **Tailscale** or **Relay**, and a direct path cuts the round trip from hundreds of milliseconds to a few. The computer must be listening on that network (`mewla --lan`); one that listens on loopback only keeps using the relay.
- **The phone proves it is talking to your computer before it trusts a direct address.** It only tries private-network addresses your computer announced to it, over a connection pinned to the computer's key, and it sends nothing from this phone until the computer has signed a fresh challenge. A wrong or reused address fails and the relay is used.
- **`MEWLA_PPROF_ADDR` shows what the daemon spends its time on.** Set it to a loopback address and the daemon serves Go's profiler plus `/debug/spawns`, a count of the helper processes it starts and why. It is off unless you set it.

## Fixed

- **Losing the direct address no longer ends the Screen.** The connection falls back to the relay, and a Screen viewer that was on a direct path retries once on its own. A phone that joins Wi-Fi after connecting through the relay moves onto the direct path within about half a minute.
- **Two Claude Workers started in the same folder no longer mix up their conversations.** Each delegated Claude Worker is now launched with its own session id, so Mewla knows which conversation is whose from the first second instead of matching it by start time. This mattered most on macOS.
- **Codex usage comes from Codex itself.** Stats used to read Codex's sign-in file and send its token to an undocumented ChatGPT address. It now asks Codex (`codex app-server`) for the plan's usage windows, so Mewla never touches that token. If Codex has no subscription windows to report, the card is hidden.
- **The Brain's Codex session is checked less often.** It looked up the running Codex process every second even when nothing had changed. It now does that once every 30 seconds.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.44.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.43...v0.2.44](https://github.com/daoleno/mewla/compare/v0.2.43...v0.2.44)
