# Mewla 0.2.41

Watch now checks whether Mewla's own notifications are worth it. Update the app to 0.2.41 as well.

## New

- **Watch judges your notifications.** Every push Mewla sends, and every one it holds back, becomes a Watch signal: the text as sent, what it was about, whether it was delivered, whether you were already in the app, and what you did with it. With Watch on, an agent reads each one in context and decides whether it was worth interrupting you, then raises ordinary Watch problems for patterns: a kind of push that is noise, badly timed or repeated, or something that needed you and never reached the phone. Each comes with what it costs and one suggested change. See `mewla watch signals --source notification`.
- **Watch flags a phone that isn't receiving pushes.** If the last three pushes all fail at the push service, it is a Watch problem, with the reason.
- **The app reports taps.** Tapping a push tells your computer which push it was and when, and the app tells it whether it is in the foreground. Nothing else leaves the phone.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.41.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.40...v0.2.41](https://github.com/daoleno/mewla/compare/v0.2.40...v0.2.41)
