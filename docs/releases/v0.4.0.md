# Mewla 0.4.0

A new Mewla app for Android and the web: rebuilt from the ground up, with a calmer look. It installs over 0.3.1 and keeps you signed in, with your computers and your drafts.

## New

- **A new app on Android and in the browser.** Same app, same pairing: it updates in place over 0.3.1. Brain is home, and what needs you sits in one place. The web app comes from your computer's daemon. On a wide screen, a computer's screen docks beside the page, and every page has its own link.
- **Start a Session with its first message.** Write what the agent should do as you open the Session. Mewla sends it once the agent is ready, a new folder's trust question included.
- **Answers stay in the thread.** Each permission, question and Work question you answered keeps a row saying what you answered and when, on the phone, in the terminal or from Brain.
- **Work tells you more.** Brain marks the answer it would pick on a Work question. A finished result offers its next steps (pull request, Git review, files), and you can snooze a Work for a set time.
- **Other computers at a glance.** See whether each paired computer can be reached, when it was last seen, and what it is waiting on you for.
- **Taps click in terminal apps.** A tap in a Session's terminal clicks in programs that take the mouse, and Codex Sessions scroll on the phone like a transcript.
- **Known issues.** iPhone stays on the 0.3.1 Preview for now. In a new Session, a message you send before the agent has started can arrive before the first one. A Session opened as a terminal only does not give back a first message it could not send.

## Fixed

- **Permission prompts name what they ask about** (for example "Run curl …"), and a prompt answered in the terminal leaves the phone.
- **The terminal stays in shape** when a Session is viewed at two sizes at once, and no longer shows broken characters where output was cut in two.
- **The keyboard goes down with its page,** sheet or tab, and the Pair camera stops when you leave it.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`.
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Windows x64:** `mewla-windows-amd64.zip`, or in PowerShell: `irm https://mewla.ai/install.ps1 | iex`
- **Android:** `mewla-android-arm64-v0.4.0.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.3.1...v0.4.0](https://github.com/daoleno/mewla/compare/v0.3.1...v0.4.0)

<summary>Verify downloads</summary>

`mewla update` and the installer check downloads for you. To check one by hand against `SHA256SUMS`:

```sh
grep 'mewla-linux-amd64.tar.gz$' SHA256SUMS | sha256sum -c -        # Linux
grep 'mewla-darwin-arm64.tar.gz$' SHA256SUMS | shasum -a 256 -c -   # Mac
```

On Windows, in PowerShell, compare with the `mewla-windows-amd64.zip` line of `SHA256SUMS`:

```powershell
(Get-FileHash mewla-windows-amd64.zip -Algorithm SHA256).Hash.ToLower()
```
