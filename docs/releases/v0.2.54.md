# Mewla 0.2.54

Mewla sends your phone only what changed, and attachments, integrations and Telegram state are kept in proper places instead of being worked out from text. Update the app and your computer together: the Session list and message sending speak a new protocol.

## New

- **Your Session list follows a numbered feed instead of a full list every 10 seconds.** The phone gets the whole list once when it connects, then each change in order. If it misses one it asks for a fresh list, and an idle connection costs a few bytes every 10 seconds.
- **Ending a Session waits for the computer's own answer.** Terminate now finishes when the computer says it ended the Session, not when the Session happens to be missing from a later list.
- **Attachments travel as files, not as text.** The phone sends a message and its files separately, the computer builds what the agent reads, and the chat shows each attachment from its own record. Messages already in your history show as before.
- **Codex's own model list is used when Codex can give it.** The model picker asks the installed Codex for its models and says where each came from; Mewla's built-in list is only the fallback.

## Fixed

- **Telegram no longer keeps every message mapping forever.** Old per-message records are pruned by thread and age, and anything a pending send, edit or reply still needs is kept.
- **Brain conversations refresh when something changed, not by checking files.** The cache follows a version the store publishes, so an unchanged store costs nothing.
- **Prices and model facts come from one place.** Usage cost and the model picker read the same models.dev data, parsed once, and the built-in price table is used only until that data has loaded, which is logged.
- **Integrations are described by one catalog.** GitHub, Slack, Notion, Linear, Google, Hyperliquid and custom MCP connections read their endpoints, scopes and tool permissions from one table, with the same permissions as before.
- **The computer no longer wastes CPU while idle.** Watching your Sessions took more than 6% of a core with nothing happening; it now takes under 1% by reading processes directly and reading a Session's screen only when it changed.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.54.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.53...v0.2.54](https://github.com/daoleno/mewla/compare/v0.2.53...v0.2.54)
