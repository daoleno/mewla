# Mewla 0.2.77

AWS calls with parameters work again, the AWS account shows who is connected, and a Session's Git button shows what you have changed.

## New

- **The AWS account shows its name, role and region.** Open it in Extensions to see which account you are connected to and who is signed in. The details stay collapsed until you want them.
- **A Session's Git button shows +N −M** in green and red when there are uncommitted changes, so you can see at a glance whether there is something to commit.

## Fixed

- **AWS calls with parameters work again.** Reads and actions that take parameters were failing; they now go through.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.77.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.76...v0.2.77](https://github.com/daoleno/mewla/compare/v0.2.76...v0.2.77)
