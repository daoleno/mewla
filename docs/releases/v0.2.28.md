# Mewla 0.2.28

You can now copy, edit and resend messages in Chat, and a stopped Claude turn no longer looks stuck. Update the app to 0.2.28 as well.

## New

- **Copy, edit and resend messages.** Press and hold a message on your phone, or hover over it (or right-click) on desktop. **Copy** gives the text as written, Markdown included. **Resend** sends your message again as a new message, once per tap. **Select text** on the phone turns on text selection for that one message.
- **Edit an earlier message.** In Claude Code, Codex and Pi, editing steps the agent's conversation back to that message and continues from your edited text; the turns after it leave the chat. The files the agent changed stay as they are, and the chip above the composer shows this with a step-back arrow, a chat bubble and a crossed-out document. With other agents, and in Brain, editing sends your edited text as a new message and nothing earlier changes.
- **Honest when it cannot rewind.** Mewla rewinds only when the agent is idle and its own message list is showing the message you picked. If it cannot prove that, nothing is rewound or sent, and your edit stays ready to send as a new message.

## Fixed

- **Stopped Claude turns.** After you stopped Claude, Chat could keep showing "Working" and a made-up message reading "[Request interrupted by user]". The turn now ends as stopped, so you can resend or edit right away.
- **Rewound conversations.** When Claude or Codex rewinds to an earlier message, from Chat or in the Terminal, Chat shows the conversation that continues from there instead of mixing in the turns that were rewound.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.28.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.27...v0.2.28](https://github.com/daoleno/mewla/compare/v0.2.27...v0.2.28)
