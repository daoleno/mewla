# Mewla 0.4.10

Brain always starts now, even when its earlier conversation is gone or its agent signs in its own way, and `mewla update` restarts Mewla wherever it runs; update Mewla on your computer.

## Fixed

- **Brain always starts.** If Brain's earlier conversation can't be resumed (after a reboot, a crash or an update from an older Mewla), it starts fresh from its workspace notes and tells you once in Chat: **Brain restarted**. Before, Brain on a computer that came from an older Mewla could stay down for good.
- **Codex with an API key or its own model provider works for Brain.** Mewla no longer holds Brain back because Codex's sign-in check says "Not logged in": Codex on an API key, a custom provider or a gateway starts and answers. `mewla doctor` no longer calls it signed out either.
- **Brain opens once you sign in.** When Brain's agent is waiting at its sign-in screen, signing in from another terminal is enough: Brain opens again by itself. "Not signed in" only shows once the agent has had time to start, with the agent's own words from its screen.
- **`mewla update` restarts Mewla even when it runs in a terminal.** Mewla restarts in place in the same window, and Ctrl+C still stops it; Sessions and Workers keep running. A Mewla 0.4.9 or earlier running in a terminal can't do this yet: after `mewla update`, stop it once with Ctrl+C and run `mewla` again. From then on, updates restart it by themselves.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`.
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Windows x64:** `mewla-windows-amd64.zip`, or in PowerShell: `irm https://mewla.ai/install.ps1 | iex`
- **Android:** `mewla-android-arm64-v0.4.10.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.4.9...v0.4.10](https://github.com/daoleno/mewla/compare/v0.4.9...v0.4.10)

<summary>Verify downloads</summary>

`mewla update` and the installer check downloads for you. To check one by hand against `SHA256SUMS`:

```sh
grep 'mewla-linux-amd64.tar.gz$' SHA256SUMS | sha256sum -c -        # Linux
grep 'mewla-darwin-arm64.tar.gz$' SHA256SUMS | shasum -a 256 -c -   # Mac
```

On Windows, in PowerShell, compare with the `mewla-windows-amd64.zip` line of `SHA256SUMS`:

```powershell
(Get-FileHash mewla-windows-amd64.zip -Algorithm SHA256).Hash.ToLower()
```
