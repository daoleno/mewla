# Mewla 0.4.6

Mewla loads again when you come back to it after a long time away, a file Brain names in Chat opens in a preview, and on Windows Claude, Codex and Brain chat all work; update Mewla on your computer too, since much of this comes from it.

## New

- **Files Brain names open in a preview.** When a reply names a file in your home folder, such as a PDF Brain wrote, tap it in Chat to open it. PDFs show their pages and zoom, an HTML file shows as a page, and pictures, Markdown and text open too. In a browser, a PDF opens in a new tab.
- **See which app version each phone runs.** `mewla devices list` shows the app version and platform each paired phone last connected with, once the phone runs this version.

## Fixed

- **Coming back to Mewla loads everything.** After a long time in the background, the app could come back with nothing loaded until you switched computers or restarted it. It now reconnects by itself and loads your messages and stats.
- **A slow connection still connects.** A slow Relay link that works no longer gives up before the app is signed in.
- **Fewer stalls.** The app signs in to your computer many times faster, keeps what your computer sends while it is in the background for when you are back, and no longer freezes when a chat with thousands of tool steps updates.
- **Windows: Claude and Codex Sessions work.** A Session could not find Claude when Claude was installed after Mewla started, and a Codex Session could end right away. Both now start and reply.
- **Windows: Brain chat replies.** Brain's replies on Windows now reach Chat, and Brain can hand work to Codex.
- **Windows: Sessions start with your setup as it is now.** A program or setting you install after signing in reaches new Sessions, the way it reaches a new terminal. A Shell Session runs PowerShell 7 when it is installed, including from the Microsoft Store, and Sessions start in your home folder.
- **Windows: `mewla web` and `mewla login` open your browser.**
- **A wrong clock says so.** When your computer's clock is hours off, `mewla login` and other requests to the Mewla service say to set the time instead of saying you are no longer signed in.
- **Help prints cleanly in Windows PowerShell 5.1.** `--help` now goes to normal output, so capturing it no longer turns every line into an error.
- **A Session on Claude's first-run theme picker asks for you.** It showed Ready while your message waited on the picker.
- **Phone use: you can always type the pairing code.** While pairing waits, a "Pairing code" notification lets you type the code, even when Mewla cannot read it from the screen. A wrong code asks again instead of ending pairing, and Mewla asks for notifications first when they are off. Android only.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`.
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Windows x64:** `mewla-windows-amd64.zip`, or in PowerShell: `irm https://mewla.ai/install.ps1 | iex`
- **Android:** `mewla-android-arm64-v0.4.6.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.4.5...v0.4.6](https://github.com/daoleno/mewla/compare/v0.4.5...v0.4.6)

(Get-FileHash mewla-windows-amd64.zip -Algorithm SHA256).Hash.ToLower()
