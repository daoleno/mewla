# Mewla 0.2.53

Permission requests from Claude and Codex show on your phone as the agent's own question with its own answers, and what you send to a Codex Worker, and a stop, now go straight to Codex.

## New

- **Permission requests are answered from the phone, not read off the screen.** When Claude or Codex asks to run a command or change files, the card shows the command and the agent's own options, and tapping one answers the agent directly. A request that was already answered, or came from another conversation, is refused instead of being typed into the terminal.
- **Messages and stop reach Codex directly.** A message you or Brain send to a Codex Worker Mewla started goes to Codex's own channel, joins the turn that is running if there is one, and carries its receipt. The stop button stops the turn without a keystroke. Profile-routed Codex Workers are followed the same way.

## Fixed

- **A Codex pane with helper threads is found.** The newer Codex lists thread status in a different shape, which made the lookup fail and left the Worker unfollowed.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.53.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.52...v0.2.53](https://github.com/daoleno/mewla/compare/v0.2.52...v0.2.53)
