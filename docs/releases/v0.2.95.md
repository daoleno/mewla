# Mewla 0.2.95

Keep the Mac awake and unlocked for as long as an agent's turn is running, connect Tailscale, and switch each model on or off.

## New

- **Tailscale.** Connect it through your signed-in Chrome, or paste an OAuth client, and agents can search, read and call Tailscale's API.
- **Model access, one switch per model.** Each Provider's menu opens a list of its models with a switch for each, following the live catalog. Turning a model off asks first, because Sessions using it start failing.

## Fixed

- **The Mac no longer locks while an agent works.** The display is held on for as long as the Worker's turn is running, however quiet it is (a long build or wait included), and for ten minutes after the turn ends; a new turn in that time keeps it. Stop, taking over, or closing the Worker let it go at once, so an idle Worker left open does not keep your Mac awake. Mewla never locks the Mac or changes its lock settings.
- **The timeline keeps your place.** New rows arriving while you scroll no longer move the part you were reading.
- **Settings is shorter.** The list of agent sign-ins is gone from Settings; Brain tells you in the conversation when an agent's login has lapsed.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.95.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.94...v0.2.95](https://github.com/daoleno/mewla/compare/v0.2.94...v0.2.95)
