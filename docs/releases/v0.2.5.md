# Mewla 0.2.5

You can play with the cat now, and messages you send no longer show up twice.

## New

- Double-tap the cat to make it hop, hold it to pet it, or hold and drag to toss it. It springs back home when you let go.
- Settings now asks for a plain server address like `https://mewla.example.com`, and says what is wrong when an address doesn't work.

## Fixed

- A message you send no longer shows up twice when it has blank lines, trailing spaces or a paste.
- The cat's wake-up hop is no longer cut off at the edges.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://raw.githubusercontent.com/daoleno/mewla/main/install.sh | sh` picks the right file for you. See [Install](https://daoleno.github.io/mewla/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.5.apk`. Android asks you to allow installs from unknown sources.
- **iPhone:** [Mewla Preview on TestFlight](https://testflight.apple.com/join/nMQheDCE)

All changes: [v0.2.4...v0.2.5](https://github.com/daoleno/mewla/compare/v0.2.4...v0.2.5)
