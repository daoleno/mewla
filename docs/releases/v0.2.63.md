# Mewla 0.2.63

The cat's tab now opens on the first try, even on a slow connection.

## Fixed

- **The cat tab no longer spins forever.** Opening the cat for the first time brings its house over in one archive instead of over a hundred separate requests, shows progress while it loads, and gives up and offers a retry after two minutes. A dropped connection costs one part of the download, not the whole thing.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.63.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.62...v0.2.63](https://github.com/daoleno/mewla/compare/v0.2.62...v0.2.63)
