# Mewla 0.2.25

Cloudflare now connects from the phone app, Plugins offers only services that connect in one tap, and Workers run on OpenCode 2 and DSH 0.2.1. Update the app to 0.2.25 as well; on iPhone it is build 63 in [Mewla Preview on TestFlight](https://testflight.apple.com/join/nMQheDCE).

## New

- **Cloudflare from your phone.** Tap **Connect** on Cloudflare in the app, approve on Cloudflare's page, and you land back in the app. Before, Cloudflare connected only from the web UI.
- **Plugins.**
  - Services that register Mewla when you connect, such as Linear and Cloudflare, now name it Mewla on their approval page, with its website and privacy policy where the service shows them.
  - Google Workspace, fal and Image generation are no longer offered for new connections. Accounts you already connected stay listed and keep working.
- **OpenCode 2.** Workers and Sessions now read OpenCode through its own service, and Mewla also finds `opencode` in `~/.opencode/bin`. OpenCode 1 is no longer supported; `mewla doctor` names the upgrade command when it finds it. OpenCode uses the model saved in OpenCode, so a Worker can't pick one at launch.
- **DSH 0.2.1.** Mewla speaks DSH 0.2.1's new sign-in and session log, and resumes its conversations.

## Fixed

- **Onlora** shows its own mark in Plugins.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.25.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.24...v0.2.25](https://github.com/daoleno/mewla/compare/v0.2.24...v0.2.25)
