# Mewla 0.2.94

Keep the Mac's display on while agents work, so it doesn't dim and lock between their steps.

## Fixed

- **The Mac no longer locks between an agent's steps.** The display is now held on from an agent's first action until its Worker ends, and for up to ten minutes after its last action (it was one minute). Stop, taking over, or the Worker ending let it go at once. Screen's details and `mewla agent-use status` say "Display kept on for agents" while it is held. Mewla still never locks the Mac or changes its lock and password settings, and a lock you make yourself stays.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.94.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.93...v0.2.94](https://github.com/daoleno/mewla/compare/v0.2.93...v0.2.94)
