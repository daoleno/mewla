# Mewla 0.2.91

Let several agents use your Chrome and your Mac at the same time, with a Mewla extension that needs no key and no store.

## New

- **Several agents in your Chrome at once.** Each agent works in a window of its own, with its tabs in a tab group named for the agent, signed in to your sites. Your own windows and tabs are left alone. Add the new **Mewla** extension once: **Set up** opens Chrome's extensions page and names the folder to load (Developer mode, Load unpacked). It needs no key.
- **Several agents on your Mac at once.** Agents acting on different apps no longer wait for each other, and one agent's actions are no longer taken for you touching the computer. Your own keyboard and mouse still pause them.
- **See and stop each agent in Screen.** Screen lists every agent using the computer by name; watch or stop one, or take over from all of them.
- **Switching Brain's host keeps the chat.** The switch no longer ends in a false timeout and carries the conversation over.
- **Claude's terminal update lines show in Brain.**
- **Screen and Session updates are paced.** Output-only updates arrive at most once every 2 seconds.

## Fixed

- **A rejected connection says which route it used.** Capacity messages from a computer name the relay or direct route.
- **Claude's approval and permission dialogs are recognized on the current layout,** and one that cannot be identified says why.
- **Agents' windows say why they failed to open** instead of timing out silently.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.91.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.90...v0.2.91](https://github.com/daoleno/mewla/compare/v0.2.90...v0.2.91)
