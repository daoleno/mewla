# Mewla 0.2.78

Friends posts can carry photos and video, and your phone no longer gets the same notification over and over.

## New

- **Friends posts can carry photos and video.** A post can have up to four photos or one video. Photos and video are cleaned before they are shared, and you review them in the draft, where each one can be removed, before anything is posted. Automatic posting never attaches media unless you turn that on in Labs.

## Fixed

- **The phone no longer gets the same notification over and over.** A prompt that blinks or keeps changing now sends one notification per question, and Worker notifications are grouped.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.78.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.77...v0.2.78](https://github.com/daoleno/mewla/compare/v0.2.77...v0.2.78)
