# Mewla 0.2.61

A session you hide can now come back, Claude and Cursor Workers are read from the conversation they are in, and Codex model changes land on the right thread.

## New

- **Brain sees a Worker's new conversation as soon as its agent starts one.** After a `/clear` or a resume the Work is linked to the new transcript right away, not up to 30 seconds later.

## Fixed

- **A session you hid now comes back when you show it again.** Hiding one took it off the list at once, but showing it again did nothing until Mewla restarted.
- **Claude and Cursor Workers are read from their own conversation file.** Mewla used to search the project folder and guess, which could pick another session's file in a busy folder. It also keeps working after Mewla restarts.
- **Changing a Codex Worker's model or effort applies to that Worker's own conversation.** It used to pick one by folder and recency, which could be a different conversation in the same folder. It now waits until Codex has announced its own.
- **A computer reports the agents Mewla can actually launch.** The list now follows the same install locations and order Mewla uses everywhere else, so an agent installed under `~/.opencode/bin` is found too.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.61.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.60...v0.2.61](https://github.com/daoleno/mewla/compare/v0.2.60...v0.2.61)
