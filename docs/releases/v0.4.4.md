# Mewla 0.4.4

Brain's chat keeps updating after a long reply, Git opens on any folder, pictures load in a few seconds on a slow connection, and the app uses far less data while Sessions run; update Mewla on your computer too, since much of this comes from it.

## Fixed

- **Brain chat no longer stops updating after a long reply.** After a long reply, Brain could stay on "Working" and show nothing new, not even your own messages, until you restarted the app. It now keeps updating.
- **Git opens on folders with huge untracked trees.** A Session folder holding a very large untracked folder made Git freeze. A new folder now shows as one row, the way `git status` shows it. Long lists show the first files with a **Show more**.
- **Pictures in a chat load faster.** The computer sends each picture at phone size, about a sixth of the data, so a thread's pictures arrive in seconds on a slow connection instead of most of a minute. Tap a picture to open it at full size.
- **Full-size pictures open on a slow connection.** A large picture could take longer than the app waited, so the connection dropped and the picture never arrived. The app now waits for it.
- **Brain opens sooner.** On a slow connection, Brain's newest messages come first, ahead of Work, Calendar and pictures, and the app no longer asks again for what the computer just sent.
- **Less data while Sessions run.** The computer no longer sends terminal text the app never shows, so a running Session's updates take a small fraction of the data they did.
- **The app stays responsive when many Sessions change at once.** Updates that arrive together are handled together.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`.
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Windows x64:** `mewla-windows-amd64.zip`, or in PowerShell: `irm https://mewla.ai/install.ps1 | iex`
- **Android:** `mewla-android-arm64-v0.4.4.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.4.3...v0.4.4](https://github.com/daoleno/mewla/compare/v0.4.3...v0.4.4)
