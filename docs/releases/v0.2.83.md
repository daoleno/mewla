# Mewla 0.2.83

Phone use (Android, Labs) opens app clones such as a second WeChat, and its floating screen is easier to live with.

## New

- **Phone use opens app clones such as a second WeChat.** Launching a clone now starts it by its own launcher, so it opens where it failed before.
- **The floating screen no longer shows a black slab.** While the agent's screen has nothing on it, it says what is happening, such as "Opening 微信…" or "Couldn't open 微信".
- **The floating screen starts in the bottom-right corner,** above the chat input, so most of the conversation stays readable. Your size and position are still remembered.
- **The floating screen goes away when the agent finishes or is closed.**
- **Agents wait a little for the phone.** If Phone use isn't ready yet, they try again for up to a minute before asking you to open Mewla.
- **Update the app and the daemon together.** Phone use needs both on this version.

## Fixed

- **Typing into an empty field no longer keeps its placeholder.** Apps like Telegram that report their hint as text no longer end up with it in front of what was typed.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.83.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.82...v0.2.83](https://github.com/daoleno/mewla/compare/v0.2.82...v0.2.83)
