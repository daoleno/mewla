# Mewla 0.2.13

Mewla on a Mac now comes back by itself after macOS restarts it for a permission.

## Fixed

- When you turn on Screen Recording for Mewla and macOS offers "Quit & Reopen", or when you open Mewla.app from Applications, Mewla now starts its background service again instead of a copy that only this Mac could reach, so your phone stays connected.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://raw.githubusercontent.com/daoleno/mewla/main/install.sh | sh` picks the right file for you. See [Install](https://daoleno.github.io/mewla/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.13.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.12...v0.2.13](https://github.com/daoleno/mewla/compare/v0.2.12...v0.2.13)
