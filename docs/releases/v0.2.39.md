# Mewla 0.2.39

Screen stays on while you use it, and keeps up on slow connections. Update the app to 0.2.39 as well.

## New

- **The display stays on while you view it.** While a phone viewer is connected, Mewla holds the Mac's display on, so it no longer switches off, locks and asks for its password in the middle of a session. The hold ends when you disconnect or the connection times out. A Mac you or someone else locks is left locked: the viewer shows a **Locked** tag, the display may sleep, and nothing is bypassed.
- **Screen keeps up on slow links.** When the phone's answers run late, Screen first allows more updates in flight, and if the bytes are what hold it back, it lowers the picture quality while the screen moves and sends it sharp again once the screen is still. When nothing is late, nothing changes. On a simulated 4 Mb/s link a scrolling page reaches the phone about twice as often.
- **The connection badge says what is slow.** Its first line names how the phone reaches the Mac (Relay, Tailscale, LAN or Local) and the slowest stage: network, encode, app or draw. It also shows when the quality is reduced. Updates per second now counts each screen update once.

## Fixed

- **An agent finishing no longer lets the display sleep under a viewer.** The display hold is counted across viewers and agents, so the last one to leave lets go of it.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.39.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.38...v0.2.39](https://github.com/daoleno/mewla/compare/v0.2.38...v0.2.39)
