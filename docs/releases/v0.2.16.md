# Mewla 0.2.16

A friendlier first run: the app wakes up with a cat, and `mewla` on your computer sets up what it needs and shows pairing on one screen.

## New

- New first-run in the app: the cat on the splash wakes up and walks you through four short steps: welcome, the one install command (copy it or send it to your computer), scan the QR code or paste the link, and you're connected.
- On first run, `mewla` checks for tmux and a signed-in agent CLI (Claude Code or Codex) and offers the official install command for your system (apt, dnf, yum, pacman, zypper, apk or Homebrew). It runs it only if you say yes, then offers to start Mewla at login.
- Existing installs get the connection question once too: run plain `mewla` and choose how your phone connects. If you already signed in for remote access, that counts as your choice.
- Pairing fits on one screen: status, a QR code that scans reliably, where to scan it, when it expires, and a short link for this computer's browser. Menus use the arrow keys. `mewla pair --details` shows everything else.
- Install with `curl -fsSL https://mewla.ai/install.sh | sh`. It no longer calls the GitHub API, so it doesn't hit rate limits.
- Settings in the app now has Privacy Policy, Support and Open-source Licenses.
- `mewla logout -delete-account` turns off remote access and deletes your remote access account.
- Tools from connected services stay current: when a service adds, changes or removes a tool, Mewla sees it right away. If an update blocks a call, the error says what changed and gives you the command that confirms it.
- The Android app is ready for Google Play. It is not in the store yet; keep installing the APK below.

## Fixed

- Android: the app no longer asks for the "display over other apps" permission, and its terminal library supports devices with 16 KB memory pages.
- If you close the connection question with Ctrl-C, or sign-in fails, Mewla no longer saves "Decide later", so the question comes back next time.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.16.apk`. Android asks you to allow installs from unknown sources.
- **iPhone:** [Mewla Preview on TestFlight](https://testflight.apple.com/join/nMQheDCE)

All changes: [v0.2.15...v0.2.16](https://github.com/daoleno/mewla/compare/v0.2.15...v0.2.16)
