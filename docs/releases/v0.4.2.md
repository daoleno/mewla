# Mewla 0.4.2

Brain and Sessions open in about a second, even on a slow connection; a chat stays put while you read it, and a Session's Git is one tap away.

## New

- **Git has its own button.** When a Session's folder is a Git repository, a Git button sits beside the Chat/Terminal button in the Session's header; it opens the repository's changes, history and files. It's no longer under **⋯**.

## Fixed

- **Brain and Sessions open faster.** With the app connected, a thread's newest messages arrive first, about a second after you open it on a slow connection, where it took 12 to 24 seconds. The rest fills in while you read. Update Mewla on your computer too: it now sends the app a third of the bytes or less, and far less while a Session only prints to its terminal.
- **New session on a Mac starts in the right folder.** A Mac's folder suggestions were `file://` addresses, so Start failed. They're plain folders now, and existing Sessions correct themselves.
- **Reading a chat no longer jumps.** A chat holds still while you scroll back through it, and after you send, it ends at your newest message.
- **Long threads keep updating.** A thread with many long commands, file writes or long outputs could stop updating and show "Mewla hit an error". Each row now reads only what it shows.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`.
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Windows x64:** `mewla-windows-amd64.zip`, or in PowerShell: `irm https://mewla.ai/install.ps1 | iex`
- **Android:** `mewla-android-arm64-v0.4.2.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.4.1...v0.4.2](https://github.com/daoleno/mewla/compare/v0.4.1...v0.4.2)

```sh
grep 'mewla-linux-amd64.tar.gz$' SHA256SUMS | sha256sum -c -        # Linux
grep 'mewla-darwin-arm64.tar.gz$' SHA256SUMS | shasum -a 256 -c -   # Mac
```

On Windows, in PowerShell, compare with the `mewla-windows-amd64.zip` line of `SHA256SUMS`:

```powershell
(Get-FileHash mewla-windows-amd64.zip -Algorithm SHA256).Hash.ToLower()
```
