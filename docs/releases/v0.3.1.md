# Mewla 0.3.1

Pairing on Android works again, and your agents can now use the screen of a Windows or Linux computer.

## New

- **Agents can use a Windows or Linux computer.** On Windows an agent works with your own screen through the apps' accessibility interface, and on Linux with its own display. Screen on Windows adds Ctrl, Alt, Shift and Win keys and tells you when the computer is locked.

## Fixed

- **Pairing no longer crashes the Android App.** After scanning the pairing link the chat opened with "Daemon is not connected." and closed; it now waits for the connection first.
- **A model added to a custom connection works right away.** When your provider adds a model, Mewla no longer refuses it until you refresh the connection's model list by hand. If a model really isn't offered, the message names the model and the connection.
- **Fewer false "Worker stopped" alerts.** A Worker that is waiting for its own background task or agent is no longer reported as lost, and one that is still writing its answer is not reported as stopped.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`.
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Windows x64:** `mewla-windows-amd64.zip`, or in PowerShell: `irm https://mewla.ai/install.ps1 | iex`
- **Android:** `mewla-android-arm64-v0.3.1.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.3.0...v0.3.1](https://github.com/daoleno/mewla/compare/v0.3.0...v0.3.1)

(Get-FileHash mewla-windows-amd64.zip -Algorithm SHA256).Hash.ToLower()
