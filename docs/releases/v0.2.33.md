# Mewla 0.2.33

Sending a message no longer asks you to retry, and the connection to your computer stays up. The row under a reply is simpler and easier to hit with a finger. Update the app to 0.2.33 as well.

## Fixed

- **Messages no longer fail with "Not delivered".** A message you send is now kept on your phone until your computer confirms it, and is sent again by itself if the connection drops. Your computer ignores a message it already received, so nothing arrives twice. Several messages sent in a row still arrive in the order you wrote them. A quiet mark beside the message shows it is on its way, and a "!" appears only when a message truly could not be delivered; tap it to send again.
- **A steadier connection.** Your computer now keeps the connection alive and drops a stalled one quickly, so the app reconnects sooner instead of sitting on a dead link.
- **Large conversations open faster.** Opening a very long Brain conversation no longer makes your computer re-read all of it each time, so the conversation loads without long waits.
- **A message Claude picked up mid-turn now shows in the conversation.** When you send a message while Claude is working, it appears in the chat as soon as Claude reads it, and the waiting clock stops.
- **Copy and ⋯ under a reply respond to a real fingertip.** The buttons under a reply now take a normal tap instead of needing an exact hit.
- **The Retry button under replies is gone.** It did not work reliably on Android and was rarely needed. The row under a reply keeps **Copy** and **⋯** (Copy and Select Text), and **Edit** on your own message stays.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.33.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.32...v0.2.33](https://github.com/daoleno/mewla/compare/v0.2.32...v0.2.33)
