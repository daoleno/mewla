# Mewla 0.2.99

Agents use one browser on every computer, an agent's live view works like using the computer yourself, and one floating screen follows you around the app.

## New

- **One browser for agents, on every computer.** Agents use the same Chrome tool on Mac and Linux. With the virtual screen on (Labs, Linux), an agent's Chrome is a window on that agent's own monitor, and Screen lists the agent, not a browser. Agents can now read a page's text, not only its controls.
- **Take over feels like using the computer (Linux virtual screen).** The agent's live view is the screen itself: mouse, wheel, keyboard and paste go straight in, and on a phone you tap, drag to scroll, long-press for a right click and type live. The Take over mode and its control panel are gone. The agent keeps going and is told what you did (counts, never what you typed).
- **Hold the agent (Linux virtual screen).** When you need a moment without interruption, choose Hold in the live view's menu: the agent's next action waits until you let go. Closing the view lets go automatically. After a Stop, the same menu offers Resume.
- **One floating screen.** Phone, Linux virtual screens and the Mac share one floating live view while an agent is using them. Drag it to a corner, resize it, Expand it to that agent's row in Screen. On Linux and the Mac, a click or key in it reaches the computer, and the agent is told and keeps going.
- **Chrome extension updates itself.** After Mewla updates, the Chrome extension reloads into the new version on its own, never while an agent has a window open.
- **The Work sheet opens at once.** The Work pill reacts as you touch it, and the sheet slides up with its cards already drawn.
- **One set of controls across the app.** Segmented choices, filter chips, rows, fields, switches, spinners and confirmations now come from one shared kit, and error notices stay until you tap or swipe them away.
- **Known limit: Phone.** Phone keeps Take over and Give back, which still pause the agent.
- **Known limit: Mac.** Mac keeps Watch and Take over as in 0.2.98: Take over stops the agents using the screen, and there is no Hold.

## Fixed

- **Virtual screen switch** now says why it can't be turned on instead of staying grey, gives up after 12 seconds, and Settings and Screen agree on its state.
- **Browser on the virtual screen** no longer gets stuck as unavailable after a slow first page.
- **Watch** could stay blank when the computer answered very quickly; it now shows the screen, and a view with no picture in 20 seconds offers Reconnect.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.99.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.98...v0.2.99](https://github.com/daoleno/mewla/compare/v0.2.98...v0.2.99)
