# Mewla 0.2.52

Brain's quick replies now sit with the message they answer, so a tap reads as a reply to Brain instead of part of its status line.

## Fixed

- **Quick replies belong to Brain's last message.** The one quiet line of answers now sits directly under that message's copy and more buttons, above the cat's status row, instead of below the status. It still scrolls sideways, hides while you type, and sends the text as typed.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.52.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.51...v0.2.52](https://github.com/daoleno/mewla/compare/v0.2.51...v0.2.52)
