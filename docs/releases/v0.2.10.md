# Mewla 0.2.10

A small follow-up to v0.2.9 so you can try the new one-tap update.

## New

- On v0.2.9, Settings → About now shows "Update available · v0.2.10". Tap it to download, verify and install this version in place. Nothing else in the app changes.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://raw.githubusercontent.com/daoleno/mewla/main/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.10.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.9...v0.2.10](https://github.com/daoleno/mewla/compare/v0.2.9...v0.2.10)
