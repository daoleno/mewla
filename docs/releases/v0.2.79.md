# Mewla 0.2.79

Your agent can now work your Android phone on its own screen while you keep using yours.

## New

- **Phone use on Android (Labs).** Your agent works your phone on its own screen while you keep using yours. Watch it live, take over, or stop it from the Phone page, the notification or the floating window. It is off by default; turn it on in Settings → Labs.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.79.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.78...v0.2.79](https://github.com/daoleno/mewla/compare/v0.2.78...v0.2.79)
