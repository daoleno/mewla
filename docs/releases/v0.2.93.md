# Mewla 0.2.93

Agents can close windows behind others and keep their apps out of your way, Screen has a cleaner picture, and iPhone use arrives in Labs.

## New

- **Agents can close a window behind others.** When an app's Close is off because it is behind other windows, the agent presses the window's close button instead, without bringing anything forward. A document with unsaved changes asks first; the agent is shown the choices and nothing is picked for it.
- **Apps an agent works in stay out of your way.** They stay on the agent display while the agent is thinking, instead of jumping back onto your screen after a minute, and return at once when you stop the agent or take over, or when its Worker is closed or its Work ends.
- **A cleaner Screen picture.** No statistics over the picture; a quiet connection dot opens the details, and held sideways the picture fills the display.
- **iPhone use, in Labs.** Settings → Labs → iPhone use lets Workers drive your iPhone through iPhone Mirroring on the Mac, off your screen. It is off until you switch it on; Screen shows the agent with Done and Stop.

## Fixed

- **Setting up Chrome never leaves a missing folder behind.** The Mewla extension's helper creates its own folder before it is written.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.93.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.92...v0.2.93](https://github.com/daoleno/mewla/compare/v0.2.92...v0.2.93)
