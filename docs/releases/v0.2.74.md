# Mewla 0.2.74

When a Worker stops on a question or an approval, Brain now hears about it and you can answer it with a tap. Plus AWS in Extensions, a better composer, and attachments on Work replies.

## New

- **Workers that stop on a question or approval are no longer silent.** Brain is told and can answer it. In the app and the web UI the card is tappable: approve, pick options, switch between several questions, then Submit. When there is nothing to tap, you see the Worker's live terminal instead of being sent to Terminal.
- **AWS in Extensions.** Connect with an AWS profile on your computer or with pasted keys.
- **A better composer.** Enter sends in Brain, you can paste or drop files, ↑ edits your last message, and drafts survive a reload.
- **Work replies can carry attachments.**
- **Desktop web layout tidy-ups.** Page headers sit over the content column, and a Session's chat and terminal share one frame.

## Fixed

- **Sending to a Worker no longer gets stuck after you answer a prompt.**
- **Reloading Friends in the browser** reopens the app instead of showing an "unauthorized" error.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.74.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.73...v0.2.74](https://github.com/daoleno/mewla/compare/v0.2.73...v0.2.74)
