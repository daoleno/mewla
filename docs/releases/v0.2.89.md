# Mewla 0.2.89

AWS and Google Cloud now work through their official command-line tools in Extensions, with the same accounts you use in your terminal.

## New

- **Connect AWS and Google Cloud from any device.** Open the remote sign-in page, then paste the code back into Mewla. If the official CLI is missing, install it with one tap.
- **Your terminal and Extensions share cloud accounts.** AWS profiles and Google Cloud accounts stay in sync when you add, rename or remove them. Compact account lists group expired accounts together, and AWS shows the sign-in limit without mistaking refreshed credentials for a longer session.
- **Agents can use your cloud tools.** `mewla aws …` and `mewla gcloud …` run reads directly; changes and secret reads require authorization. AWS now uses its CLI instead of the previous MCP connection.

## Fixed

- **Web pages stay visible when you switch tabs.** Routes load with the app, so opening another page no longer waits for a separate route download.
- **Sign-in can recover when it returns to another computer.** A copy page lets you bring the result back to the Mewla computer where you started.
- **Brain no longer gets stuck during startup** when a computer receipt is replayed across threads.
- **Computer replies reach the Worker that sent the request.**

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.89.apk`. Android asks you to allow installs from unknown sources.
- **iPhone:** [Mewla Preview on TestFlight](https://testflight.apple.com/join/nMQheDCE)

All changes: [v0.2.88...v0.2.89](https://github.com/daoleno/mewla/compare/v0.2.88...v0.2.89)
