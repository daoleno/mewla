# Mewla 0.2.27

Answering Claude's multiple-choice questions is now as quick as in the terminal, and links in replies open properly. Update the app to 0.2.27 as well.

## New

- **Answer Claude's questions one at a time.** The "Waiting for your choice" card now shows one question per step, with a tab for each question and a final **Review** step. Tapping an option on a single-choice question moves straight to the next one, several-choice questions use checkboxes, and **Type something** is a single row instead of a big card. Review shows every answer, lets you change any of them, and counts the questions you have not answered before **Submit**.
- **Links in replies.** Bare URLs, `<url>` links and links in brackets now open from agent replies, the Brain viewer and file previews. A link to a file opens it in the Session file preview with Download, and a URL next to Chinese text ends at the full-width punctuation.
- **Work details.** Work details now show tables, task lists, rules and numbered lists the way Session replies do.

## Fixed

- **Choice card under the header.** A long question list no longer scrolls under the Brain and Session header; the card stays below it and scrolls inside itself.
- **Dead links.** A link that cannot open, such as a blocked scheme or a file this screen cannot open, shows as plain text instead of a link that does nothing.
- **Messages that stayed pending.** A message you sent could stay marked as pending after it had arrived, because the app compared it with the wrong position in the conversation.
- **Slack sign-in.** Slack now returns to the app through Mewla's own https page.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.27.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.27-beta.1...v0.2.27](https://github.com/daoleno/mewla/compare/v0.2.27-beta.1...v0.2.27)
