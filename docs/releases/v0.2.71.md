# Mewla 0.2.71

Turning on Friends no longer turns on remote access, and Brain's reply suggestion buttons are gone.

## Fixed

- **Turning on Friends no longer turns on remote access.** It now signs this computer in to your Mewla account and nothing more. If you already signed in to Friends on a computer, run `mewla logout` once to turn remote access off; Friends keeps working. With Friends on, `mewla logout` only turns remote access off.
- **The reply suggestion buttons under Brain's messages are gone.**

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.71.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.70...v0.2.71](https://github.com/daoleno/mewla/compare/v0.2.70...v0.2.71)
