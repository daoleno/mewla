# Mewla 0.2.59

A scheduled action now gives Brain exactly one Work for each run.

## Fixed

- **Scheduled actions no longer log routing errors.** Every run logged two warnings (`status "running" is derived` and `Attempt Sessions cannot be assigned by Work update`) because Mewla tried to set a state on the run's Work that only the Work lifecycle may set. The run's Work now waits on the run's result, records its launch and result once each, and finishes when the run does. A recurring item's next run gets its own Work, and a daemon restart or replay mid-run changes nothing.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.59.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.58...v0.2.59](https://github.com/daoleno/mewla/compare/v0.2.58...v0.2.59)
