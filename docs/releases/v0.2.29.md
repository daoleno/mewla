# Mewla 0.2.29

Copy, edit and retry in Chat now work on your phone. Update the app to 0.2.29 as well.

## New

- **Press and hold a message.** A sheet opens with **Copy**, **Select Text** and, on your own messages, **Edit**. Select Text shows the message in a sheet where you can select any part of it. Edit puts the message in the composer with a small bar to cancel; sending it steps Claude Code, Codex and Pi back to that message and continues from your text, and with other agents and in Brain it sends your text as a new message.
- **Copy and Retry under the newest reply.** The two icons are always there. Retry runs your last message again the same way Edit does.
- **Search Brain's memory.** `mewla memory search` and `mewla memory show` find what you said or decided in Brain chat, and each Work links to the conversations of its Workers.

## Fixed

- **Press and hold did nothing on Android.** The menu in 0.2.28 never opened; it now opens on every message.
- **Editing your first message.** In Claude Code, editing the very first message left the chat blank and the new reply never showed. It now shows the conversation from your edited message.
- **Sending an edit with Enter.** On desktop, Enter did not send an edited message.
- **Less to read.** The extra explanation above the composer and the separate Resend item are gone.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.29.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.28...v0.2.29](https://github.com/daoleno/mewla/compare/v0.2.28...v0.2.29)
