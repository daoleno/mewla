# Mewla 0.2.34

Mewla now brings the problems Watch finds to Brain, and Brain tells you about the ones that matter. Update the app to 0.2.34 as well.

## New

- **A morning brief from Brain.** At 08:30 your time, Brain sends one message that lists the three to five problems nobody is handling, one plain line each: what it is and what it costs. If there is nothing, you hear nothing. You get one normal Brain notification, and the brief follows the language you write in.
- **Answer in a tap or in words.** Brain messages can show a row of quick replies under them. Tapping one is the same as typing it, so you can also write "1 handle, 3 not a problem". The row goes away when the conversation moves on.
- **Brain triages what Watch finds.** New problems reach Brain in batches. Brain closes noise with a reason, ties problems to the Work that handles them, and keeps the rest. Problems move to fixing when Work starts on them and to fixed once that Work is accepted, and they come back if the same thing breaks again.
- **Clear, serious problems reach you at once.** A red build on a default branch or a very costly problem is pushed right away, once. Everything else waits for the brief.
- **Watch picks its own agent.** Watch no longer needs Claude Code. It uses the agent running Brain, or any installed one (Claude Code, Codex or Pi), with no tools, no saved session and secrets removed. To choose, add a row beginning with "Watch judgment" to routing.md in your Brain workspace, with the agent, the model and the reasoning level.

## Fixed

- **A fixed build no longer looks broken.** Watch now judges each workflow by its latest run on the default branch, and a newer green run closes the problem. A build that is already green no longer causes a push.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.34.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.33...v0.2.34](https://github.com/daoleno/mewla/compare/v0.2.33...v0.2.34)
