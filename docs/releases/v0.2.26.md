# Mewla 0.2.26

Slack connects from the phone app, and Plugins drops fal, Image generation and Google Workspace. Update the app to 0.2.26 as well; on iPhone it is build 64 in [Mewla Preview on TestFlight](https://testflight.apple.com/join/nMQheDCE).

## New

- **Slack.** Tap **Connect** on Slack in the app and approve on Slack's page. Mewla's Slack app isn't publicly distributed yet, so for now Slack accepts it only in Mewla's own workspace.
- **Plugins.**
  - fal and Image generation are removed. When your server starts, it deletes their accounts and saved API keys. Onlora generates images, speech and video.
  - Google Workspace no longer appears in Plugins, including on servers that already have a Google account.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.26.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.25...v0.2.26](https://github.com/daoleno/mewla/compare/v0.2.25...v0.2.26)
