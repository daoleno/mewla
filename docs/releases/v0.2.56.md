# Mewla 0.2.56

Pi Workers are followed through an extension Mewla loads into each Pi it starts, so their turns end the moment Pi says so, and what you send and stop reaches Pi without typing into its terminal.

## New

- **Pi Workers report their own turns.** A turn starts and ends when Pi says so, an aborted turn is told apart from a failed one, and the Pi session Mewla started stays the Worker's conversation.
- **Messages and Stop reach Pi directly.** What you or Brain send to a Pi Worker is handed to Pi and confirmed by Pi, not pasted into the Terminal, and Stop aborts the running turn.
- **Two Cursor Workers in one folder no longer get each other's conversation.** Mewla creates the chat before it starts Cursor and resumes it, so each Worker's transcript is known from the first moment instead of being matched by time.

## Fixed

- **A Codex Worker's conversation is read from its own thread.** Mewla used to search Codex's database and open files for it every time the chat refreshed; for a Codex that Mewla started, it now opens the thread Codex announced, so the chat shows only that thread and costs no search.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://mewla.ai/install.sh | sh` picks the right file for you. See [Install](https://mewla.ai/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.56.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.55...v0.2.56](https://github.com/daoleno/mewla/compare/v0.2.55...v0.2.56)
