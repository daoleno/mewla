# Mewla 0.2.6

The cat now tells you how many Workers are running, and the Android app is a smaller download.

## New

- The line under the cat says how many Workers are running, like "3 Workers running". Tap it to see the Work list.
- The Android app is a smaller download: it no longer carries font data it didn't use.

## Get it

- **Already installed?** Run `mewla update` on your computer, and install the new APK on Android.
- **New here?** `curl -fsSL https://raw.githubusercontent.com/daoleno/mewla/main/install.sh | sh` picks the right file for you. See [Install](https://daoleno.github.io/mewla/docs/install/).
- **Mac (Apple Silicon):** `mewla-darwin-arm64.tar.gz`. Needs `tmux` (`brew install tmux`).
- **Linux x64:** `mewla-linux-amd64.tar.gz`
- **Linux ARM:** `mewla-linux-arm64.tar.gz`
- **Android:** `mewla-android-arm64-v0.2.6.apk`. Android asks you to allow installs from unknown sources.

All changes: [v0.2.5...v0.2.6](https://github.com/daoleno/mewla/compare/v0.2.5...v0.2.6)
