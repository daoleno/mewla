隐私政策

Mewla 让你在自己的电脑上运行 AI Agent，并在手机上使用它们。你的工作只在你的设备和你的电脑之间流动。

最后更新：2026 年 10 月 15 日。如与英文版不一致，以英文版为准。

  • Mewla App 和你电脑上的 mewla 程序不发送任何统计、遥测或崩溃报告。没有广告，没有跟踪。
  • 你的会话、提示词、文件、终端和屏幕只在你的手机和你自己的电脑之间传输。我们收不到。
  • 只有当你打开远程访问（mewla login）时，我们才保存一个很小的账号：你的 GitHub id 和用户名，以及你登录的每台电脑的地址和名字。
  • 你随时可以用 mewla logout -delete-account 删除这个账号。

我们是谁

Mewla 由 daoleno（下称“我们”）开发。对本政策或你的数据有疑问，请写信到 support@mewla.ai。

App 和你的电脑

Mewla 分两部分：手机上的 App，和运行在你自己电脑上的 mewla。App 只和你配对过的电脑通信。你在 App 里看到和发送的一切（会话、聊天、终端、文件、Brain、日历、Work、屏幕）都在你的手机和那台电脑之间传输。我们没有保存这些内容的服务器，也看不到它们。

  • App 里没有账号。你用一次性配对码把 App 和电脑配对，不需要注册。
  • 手机上，App 保存配对过的电脑列表、每次配对的私钥（在 iOS 钥匙串或 Android Keystore 里）和你的设置。卸载 App 就会删除它们。
  • 电脑上，mewla 把状态保存在你掌控的文件夹里（默认 ~/.mewla）：已配对的设备、Brain 的笔记、Work 记录、上传的文件和设置。具体存了什么。
  • 相机只用来扫描配对二维码，不录制，也不发送到任何地方。
  • 通知。日历提醒在手机本地安排。如果你的电脑给你发推送通知，它会经过 Expo 的推送服务，再由 Apple 或 Google 送到你的手机。
  • 更新。从 GitHub 下载的 Android App 会去 GitHub Releases 检查新版本。App Store 和 Google Play 的版本不会。

AI Agent 和模型服务

Claude Code、Codex 等 Agent 和 Mewla 的 Brain 都运行在你的电脑上。你使用它们时，是你电脑上的 Agent 把你的提示词，以及它决定附带的文件或命令输出，发给你选择的模型服务（例如 Anthropic 或 OpenAI），用的是你自己在那家服务的账号或 API key。Mewla App 不会把它们发给任何模型服务，我们也收不到。模型服务收到的内容，适用它自己的隐私政策。

你在电脑上连接的其他服务（例如 GitHub、Telegram）也一样：由你的电脑直接和它们通信。

远程访问（可选）

运行 mewla login 后，你的电脑会得到一个地址，例如 quiet-otter-3f9a.m.mewla.ai，这样手机在任何网络下都能连上它。这是我们运营的唯一一项服务。不用它也能用 Mewla（在自己的局域网里，或者通过 Tailscale 或你自己的隧道）。

账号服务保存什么

  • 你的 GitHub 用户 id 和用户名。你用 GitHub 登录；我们只申请读取你 GitHub 资料的权限，并且不保存 GitHub 令牌。
  • 你登录的每台电脑：它的地址、你给地址起的名字（如果有）、它的公钥，以及登录时间和最近一次连上的时间。
  • 用过的地址会一直保留，但不带任何能关联到你的信息，这样同一个地址永远不会再分给别人。在某个地址配对过的浏览器，可能还存着这个地址的密钥。

中继做什么

中继在你的设备和你的电脑之间转发加密流量。加密在你的电脑上终止，只有你的电脑有密钥，所以中继读不到经过的内容，也不记录内容。它只统计连接数和字节数的总量。

IP 地址

中继和账号服务能看到每个连接的 IP 地址。它们把 IP 保存在内存里用来防滥用（例如同一个地址一小时最多登录 10 次），并把连入设备的地址转给你的电脑，你的电脑也用它做同样的限制。两者都不把 IP 地址写进日志。服务器的防火墙会记录它拒绝的、或对不上任何连接的网络包，包括来源 IP，这些日志大约五周后删除。

日志和备份

账号服务会记录登录、登出、改地址和删除账号，带上账号 id、GitHub 用户名和电脑地址。这些日志有大小上限，新内容写入时会删除最旧的部分。我们会备份账号数据库；已删除的账号最多在备份里留 30 天，直到那份备份被删除。

证书和其他服务商

  • 你的电脑会从 Let’s Encrypt 获取自己的 HTTPS 证书。和所有公开证书一样，它会出现在公开的证书透明度（Certificate Transparency）日志里，所以你电脑的地址是公开的。除非你自己起名，地址是两个随机单词。
  • 服务运行在我们向 OVHcloud 租用的服务器上，域名解析由 Cloudflare 托管，登录通过 GitHub。

删除你的数据

  • 远程访问账号。在任意一台还用这个账号登录着的电脑上运行 mewla logout -delete-account，输入账号名确认。这会删除你的 GitHub id 和用户名，以及这个账号下的所有电脑；其他电脑会在一小时内掉线。如果已经没有登录着的电脑，用同一个 GitHub 账号登录一次（mewla login）再运行这个命令，或者用你 GitHub 账号的邮箱写信到 support@mewla.ai。
  • 只移除一台电脑。mewla logout 会把这台电脑从账号里移除。
  • GitHub。如果也想撤销 Mewla 在 GitHub 上的授权，到 github.com/settings/applications 撤销。
  • 其他数据都在你自己的设备上：卸载 App，并删除电脑上的状态文件夹（~/.mewla）。

本网站

mewla.ai 托管在 GitHub Pages 上，并从 Google Fonts 加载字体。和任何网站服务器一样，它们在你访问时能看到你的 IP 地址和浏览器信息，适用它们各自的隐私政策。本网站不设置 cookie，没有统计分析。它会在浏览器的本地存储里记住你选的宠物，这个信息不会离开你的浏览器。
