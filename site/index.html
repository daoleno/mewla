Zen is an open-source phone app for the coding agents on your own computer.

i

Begin

Start any agent in any folder on your computer. Each one is a Session: read it as a conversation, or take the live terminal.

claude · codex · cursor · grok · pi · opencode · shell

ii

Let go

Give Brain a goal. It writes the Work down, hands each part to a Worker Session, and reads every result before closing it. Open any Worker to take over.

iii

Return

While they run, your phone stays quiet. When a Session is blocked, fails or finishes, you are called, here or on Telegram.

iv

Yours

Zen runs on your computer and answers to one owner. A phone pairs once, then signs every request. Code, keys and agent state stay with you; model providers see only what agents send them.

Several agents skip approval prompts by default so they can work alone. On a machine with secrets, use the safe profile.

One line to begin.

curl -fsSL https://raw.githubusercontent.com/daoleno/zen/main/install.sh | sh

Then start zen --lan and scan the code it prints with the app.

Linux, WSL2 or an Apple Silicon Mac, with tmux and one signed-in agent CLI. The app: Android on Releases; iOS from source, with a TestFlight preview awaiting review.

Beta. Apache 2.0.
