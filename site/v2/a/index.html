Open source. Runs on your own computer.

Run every coding agent from your phone.

Zen is a phone app for Claude Code, Codex and the other coding agents on your computer. Start them in any folder, watch them work, and get called only when one needs you.

Built for developers who keep several agents running at once.

  • Open source, Apache 2.0
  • Self-hosted daemon
  • Android and iOS (beta)

What it does

Many agents at work. One phone, one owner.

  1. 一Every agent, one place

    Start Claude, Codex, Cursor, Grok, Pi, OpenCode or a plain shell in any folder on your computer. Read each Session as chat, or take the live terminal.

  2. 二Hand off the goal

    Tell Brain what you want. It turns the goal into Work, hands each part to a Worker Session and reviews every result before it closes. Open any Worker to take over.

  3. 三Called only when it matters

    While agents run, the phone stays quiet. When a Session is blocked, fails or finishes, you get an alert on the phone or in Telegram.
